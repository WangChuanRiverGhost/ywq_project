# 周一：函数是对象；闭包  

### 1、什么是闭包？闭包和普通函数的区别？  
闭包是一个属性，只在存在函数嵌套且内部函数调用了外部函数的变量时存在值；  
用于更方便调用某函数内部的函数；  
普通函数通常返回一个（或多个）值，闭包的函数返回内部的函数对象。
### 2、为什么说"函数是一等公民"？这跟装饰器有什么关系？  
函数是python的对象，存在属性，可以被赋值给变量，可以被当作参数或者返回值；  
函数是对象代表它可以是一个函数的参数，而装饰器的本质就是接收函数为参数，并返回一个新函数。

# 周二：装饰器入门
### 1、装饰器是什么？解决什么问题？  
装饰器是一个给原有函数添加新功能的函数，传入一个函数并返回一个新函数；  
当需要对某一堆函数批量加同样的功能，并且不改变其原本的内部逻辑时可以使用装饰器。
### 2、装饰器的原理是什么（用"高阶函数 + 闭包"解释）？
装饰器本质上是一个接收函数并传出新函数的高阶函数；
装饰器通过闭包属性，在其内部复制一份func_a并在装饰器内部创建一个新的func_b，在func_b中调用func_a,在func_a的基础上增加新的功能，然后返回func_b。
