# 周一：函数是对象；闭包  

### 1、什么是闭包？闭包和普通函数的区别？  
闭包是一个属性，只在存在函数嵌套且内部函数调用了外部函数的变量时存在值；  
用于更方便调用某函数内部的函数；  
普通函数通常返回一个（或多个）值，闭包的函数返回内部的函数对象。
### 2、为什么说"函数是一等公民"？这跟装饰器有什么关系？  
函数是python的对象，存在属性，可以被赋值给变量，可以被当作参数或者返回值；  
函数是对象代表它可以是一个函数的参数，而装饰器的本质就是接收函数为参数，并返回一个新函数。

# 周二：装饰器入门
### 1、装饰器是什么？解决什么问题？  
装饰器是一个给原有函数添加新功能的函数，传入一个函数并返回一个新函数；  
当需要对某一堆函数批量加同样的功能，并且不改变其原本的内部逻辑时可以使用装饰器。
### 2、装饰器的原理是什么（用"高阶函数 + 闭包"解释）？
装饰器本质上是一个接收函数并传出新函数的高阶函数；
装饰器通过闭包属性，在其内部复制一份func_a并在装饰器内部创建一个新的func_b，在func_b中调用func_a,在func_a的基础上增加新的功能，然后返回func_b。

# 周三：装饰器进阶
### 1. `functools.wraps` 是干什么的？不加会有什么问题？
functools.wraps用于复制函数属性，在定义内部包装函数时，把原函数的函数属性复制到包装函数上；  
不加的话会导致最终获得的被装饰过后的函数属性是装饰器的函数属性，一些需要查看被装饰的函数本身的函数属性的场景时，会导致出问题，看到的不是我们的期望值或信息，或出现某些依赖于函数属性的方法的bug。
### 2. 带参数的装饰器为什么是"三层嵌套"？每层分别接收什么？
当存在语法糖@时，带参数的本质是给语法糖后的装饰器传入参数，如果我们需要传入除函数以外的参数，首先，不能直接写`@a(func,num)`，下面不写任何的函数，因为这样不符合语法规范；其次，如果直接写`@a(num)`下面加入我们想要装饰的函数，python则只会传一个num参数到a。但我们的期望是传入num和func两个参数，这样就会导致a只接收到一个num参数从而报错。所以为了把外部参数传入装饰器内部，并让其中的函数通过闭包原理使用传入的外部参数，就只能使用三层嵌套，也就是说，在带参数的装饰器中，实际上传入的参数是通过闭包，在原函数被调用时让最内层装饰的函数进行使用。而大多数情况来讲，三层以上的装饰器，如四层、五层很少使用，因为通过传入*args和**kargs，三层嵌套已经可以满足大部分需求。  
第一层接收参数，返回第二层的函数；  
第二层接收被装饰的函数，返回第三层的函数（即被装饰后的函数）；
第三层通过闭包机制，接收原函数被调用时传进来的实参  

# 周四：装饰器实战+上下文管理器入门
### 1. `with` 语句的原理是什么？
当with开始执行时，调用指定类中的`__enter__`方法，并获取其返回值赋予给as后的变量。with块结束后，无论是否报错都执行`__exit__`。
### 2. `__enter__` 和 `__exit__` 分别做什么？`__exit__` 的三个参数是什么？
`__enter__`被调用并返回数据被as后的变量引用；  
`__exit__`在with代码块结束后执行，通常用于处理异常或回滚数据；  
第一个参数是异常类型，第二个参数是异常实例，第三个参数是产生异常时的内存地址。
