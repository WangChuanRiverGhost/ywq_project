# 类装饰器
### 1、调用类装饰器  
可以通过`__call__`的方式把类作为一个装饰器：
```python
class hello:

    def __init__(self,func):
        self.func = func
    
    def __call__(self):
        print("你好")
        result = self.func()
        print("拜拜")
        return result

@hello
def print_aaa():
    print("aaa")
    return

print_aaa()
```
语法糖后也可以改成：
```python
def print_aaa():
    print("aaa")
    return

p = hello(print_aaa) 

p()
```
实际上，`__call__`是当调用实例时，自动触发的函数。
### 2、把类传入装饰器
当类被传入装饰器时，传入的是类，传出的也是类，装饰器实际上修改的是类的方法。
```python
class HelloWorld:
    def __init__(self):
        self.name = "修改前"

n = HelloWorld()
print(n.name)

def x(text):
    def y(cls):
        original_init = cls.__init__
        def new_init(self):

            original_init(self)
            self.name = text

        cls.__init__ = new_init
        return cls
    return y

@x("hello world")
class HelloWorld:
    def __init__(self):
        self.name = "修改前"

m = HelloWorld()
print(m.name)
```
输出：
```text
修改前
hello world
```
# with语句
### 1、with调用对象
with调用的对象是上下文管理器。当一个类中存在`__enter__`和`__exit__`魔术方法时，我们就认为它是一个上下文管理器。  
### 2、with调用原理
开始调用时，with寻找类中的`__enter__`方法调用，并将返回值（return后的值）赋值给as之后的变量；  
结束调用后（即with代码块结束后），with寻找类中的`__exit__`方法并调用（无论在执行with语句时是否报错）。  
所以，对于`__exit__`来讲，它可以决定在with中的异常如何处理，更加安全。  
有时，也会在`__exit__`中实现数据回滚。
```python
class myWith:
    def __enter__(self):
        print("正在执行__enter__")
        a = "返回的数据a"
        return a

    def __exit__(self, exc_type, exc, tb):
        if exc_type is not None:
            print(f"出现错误，错误信息：{exc}")
            print(tb)
        return False

with myWith() as i:
    print(i)
    raise ValueError("什么都没有，只是想报个错")
```
输出：
```text
正在执行__enter__
返回的数据a
出现错误，错误信息：什么都没有，只是想报个错
<traceback object at 0x000002B3EC12A340>
Traceback (most recent call last):
  File "d:\实训\学习计划\第三周\作业代码\day12_context.py", line 15, in <module>
    raise ValueError("什么都没有，只是想报个错")
ValueError: 什么都没有，只是想报个错
```
当with块中出现错误时可以被`__exit__`捕获而不是直接崩溃，可以选择是否在with中处理错误。  
如果`__exit__`返回True，无论是否存在报错都不会使程序崩溃；反之，返回False则相反。
