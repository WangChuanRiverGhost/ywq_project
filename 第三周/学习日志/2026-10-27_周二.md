# 装饰器
装饰器本质是传入一个函数，并返回一个新函数，且为旧函数增加新功能的方法。  
从定义来讲，装饰器可以写成这样：  
```python
def hello():
    print("你好")

def happy(func):
    def you_happy():
        func()
        print("祝你天天开心")
    return you_happy
```
调用时传入一个函数对象的参数：  
```python
a = happy(hello)
a()
```
但为了简便，python加入了@语法：
```python
def happy(func):
    def you_happy():
        func()
        print("祝你天天开心")
    return you_happy

@happy
def hello():
    print("你好")
```
上述代码通过@，将hello当作参数传入happy()中，返回you_happy。  

装饰器可以被嵌套使用。当某个装饰器内部的函数也需要传入参数时：  
```python
def hello(text):
    def you(func):
        func()
        print("祝你")
        def happy():
            print(text)
        return happy
    return you

@hello("天天开心")
def a():
    print("aaa,")
```
执行上述代码时，@hello("天天开心")实际上是@you，即实际上将a()传入了you(func)
