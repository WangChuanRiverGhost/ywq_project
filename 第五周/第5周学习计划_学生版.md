### 学新知识

**1. HTTP 是什么**（和原计划一样）

浏览器（客户端）向服务器"请求"，服务器"响应"。请求 = 方法 + 路径 + 请求头 + 请求体；响应 = 状态码 + 响应头 + 响应体。

**2. 5 个常用方法（背下来）**

| 方法 | 作用 | 对应数据库操作 | 2026 优化版面试高频 |
|---|---|---|---|
| GET | 查 | SELECT | ⭐⭐⭐⭐⭐ |
| POST | 增 | INSERT | ⭐⭐⭐⭐⭐ |
| PUT | 改（整体） | UPDATE | ⭐⭐⭐ |
| DELETE | 删 | DELETE | ⭐⭐⭐ |
| PATCH | 改（部分） | UPDATE | ⭐⭐ |

**3. 状态码分类（背下来）**

| 分类 | 含义 | 例子 | 2026 优化版面试高频 |
|---|---|---|---|
| 2xx | 成功 | 200 OK、201 Created | ⭐⭐⭐⭐⭐ |
| 3xx | 重定向 | 301 | 偶尔问 |
| 4xx | 客户端错误 | **400、401、403、404、422** | ⭐⭐⭐⭐⭐（2026 优化版额外标红这 5 个） |
| 5xx | 服务器错误 | 500 | ⭐⭐⭐⭐ |

> **2026 优化版特别提醒：面试常问 401 vs 403 vs 422 的区别，记牢：**
> - **400** = 请求格式错（比如 JSON 结构不对）
> - **401** = 没登录 / Token 失效
> - **403** = 已登录但没权限
> - **404** = 资源不存在
> - **422** = 参数校验不通过（FastAPI 高频返回，比如 Pydantic 模型校验失败）

### 动手写代码（`2026-11-13_day21_todo_api.py`）

实现 5 个接口（完整 CRUD），和原计划一样：

| 方法 | 路径 | 作用 | 2026 优化版特别检查 |
|---|---|---|---|
| POST | `/todos/` | 新增待办 | 用 Pydantic 模型接收参数 |
| GET | `/todos/` | 查所有 | 返回列表 |
| GET | `/todos/{todo_id}` | 查某一条 | ⚠️ id 不存在时应该返回什么？（404） |
| PUT | `/todos/{todo_id}` | 修改某一条 | 整体修改，还是只改某字段？ |
| DELETE | `/todos/{todo_id}` | 删除某一条 | id 不存在时返回什么？ |

> **2026 优化版常见坑提醒（必须看！）**
> 1. `todos = []` 重启服务器就清空了——没事，内存版就这样，第 7 周换 MySQL
> 2. 路由顺序：`/todos/{todo_id}` 必须写在 `/todos/` **后面**，不然 `list_all` 里的 `todos` 会被当成路径参数
> 3. `new_id = len(todos) + 1` 删了再新增 id 可能重复——没事，2026 优化版先不纠结
> 4. **Pydantic 校验不通过时 FastAPI 返回的是 422 不是 400**——记住 422，面试高频

> **2026 优化版 MySQL 小铺垫：** 今天用的是 `todos = []` 内存列表。第 7 周换 MySQL 时，大概要改这些：
> - 导入 SQLAlchemy 代替内存列表
> - 定义 Todo 数据库表结构（和 Pydantic 模型长得有点像）
> - 把 `todos.append(item)` 改成 `db.add(item)` + `db.commit()`
> - 把 `for item in todos if item["id"] == todo_id` 改成 `db.query(Todo).filter(Todo.id == todo_id).first()`
>
> 现在先知道大概就行，第 7 周再系统学。
