# 周二（11 月 10 日）：HTTP 基础 + MySQL vs SQLite 对比 + Cursor 初练
### 1. HTTP 有哪 5 个常用方法？GET 和 POST 区别？
GET,POST,PUT,HEAD,DELETE;  
get只是发起拿数据的请求，只进行数据读取。post会进行数据提交
### 2. 状态码 200、400、401、403、404、422、500 分别代表什么？
200是请求成功；  
4开头是客户端请求无法成功。400是请求语法或参数有误，401是未认证，403是认证了但是没权限，404是请求了不存在的资源，422是语法正确的情况下传了不合法的语义/业务逻辑；  
5开头是服务器出问题。500是服务端内部有误。
### 3. 什么是 RESTful 接口？
RESTful是一种架构风格，没有状态且接口统一为url标识比如/users/11，客户端通过json操作资源而不是sql语句。
### 4. **MySQL 和 SQLite 有什么区别？为什么公司要用 MySQL？**
MySQL是一种服务，需要搭建服务器并联网运行，sqlite完全是本地运行，直接操控磁盘数据。  
MySQL可以应对高并发场景，sqlite则相对来讲比较单一，只能单个用户使用。MySQL不仅可以多用户使用，还可以根据用户不同划分不同等级。

# 周三（11 月 11 日）：FastAPI 入门 + Apifox 平替 + Cursor 写接口实战
### 1、FastAPI 是什么？和普通 Python 脚本有什么区别？
fastapi是一种web框架，用于构建API。  
会自动监听端口，有http请求后进行处理
### 2、@app.get("/") 里的 / 是什么意思？
括号中是url路径，当路径是“/”时代表发来对根目录的http请求时进行处理，即/是运行目录
### 3、Swagger 是干什么用的？
根据代码自动生成api文档，并且可以试验参数和返回值
### 4、Postman 和 Apifox 有什么区别？你两个都会用吗？
postman是调试接口用的，apifox更侧重于“api流程”的集合，通过统一数据源的方式减少协作成本
