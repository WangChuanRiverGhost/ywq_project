# FastAPI
fastapi是一个用python类型提示来声明API的框架。即通过传入声明类型的参数，fastapi内部进行校验等，来调用不同的我们自己的后端功能。
## 使用方式
创建FastAPI实例、通过实例注册路由、创建要进行的操作函数
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def a():
    return {"msg":"a"}
```
```cmd
uvicorn main:app
```
# apifox
apifox是一个协作平台，承包了“接口文档+调试+mock+测试”四部分功能。  
其中的核心有三个部分：  
### 1、编排 将业务顺序排成步骤
### 2、提取变量 前一步的响应值提取后给后一步用
### 3、断言 可以直接在表单中选择断言对象以及填写期望值
## 变量
环境变量、全局变量、临时变量（优先级：临时>环境>全局）
