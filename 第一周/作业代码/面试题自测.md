# 周一（10月12日）：变量、数据类型、条件与循环

1. Python有哪些基本数据类型？各举一个例子
    有五种，整数12，浮点数3.12，字符串"你好”，布尔值True、False，空值None
2. `==` 和 `=` 的区别是什么？
    ==是在比较两者的值是否相等，=是将=前的变量指向=后的变量所指向的内存中的数据，最终结果是=前后的变量同时指向内存中的同一个数据
3. break和continue的区别？
    break是直接终止循环，contiue是跳出本次循环，继续这层循环代码的下一次循环
4. 为什么Python用缩进而不是大括号？
    让代码更易读

# 周二：函数、参数、作用域

1. `*args` 和 `**kwargs` 的区别？
    *args传入元组/列表，在函数内部自动转化为元组；**kwargs传入字典，在函数内部自动转化为字典
2. 默认参数的注意事项？（提示：`def func(a, lst=[])` 有什么问题？）
    默认参数需要是不可变的数据，或在函数内部使其为空。否则可能会出现存在调用残留数据的情况。
3. 函数返回多个值时，实际返回的是什么类型？
    元组
4. 局部变量和全局变量的区别？`global`关键字什么时候用？
    局部变量出该局部作用域后不可用；在调用时python优先寻找局部变量。当需要在局部作用域中用到全局变量时，用global声明。

# 周三：异常处理

1. try/except/else/finally的执行顺序？
    优先执行try，当try中的错误被成功捕获，可以通过except对其捕获的错误情况进行处理；当try中没有出现问题，执行else；无论try有没有错误被捕获，在except或者else后执行finally。
2. `except Exception as e` 中的 `e` 是什么？
    具体的错误信息
3. 什么时候用raise？什么时候用try/except？
    当一些错误不在程序可识别的范畴内时用raise，如计算bmi值，如果传入数据为负数，在程序里是可以跑通算出来一个负数结果的，并且不会报错，但是我们期望最终呈现的bmi值这个结果不为负数，此时可以用raise；
   当我们期望对错误信息进行处理而不是让程序直接报错时使用except。
4. `finally` 通常用来做什么？
    执行在这个代码块中无论是否报错都进行下去的程序
