# 周三：异常处理

写函数 check_password(password)
    长度<6：raise ValueError("密码太短")
    长度>20：raise ValueError("密码太长")
    没有数字：raise ValueError("密码需要包含数字")
    全部通过：return "密码合法"
给 `check_password` 函数写测试清单：
- 正常情况："abc123"（长度6，有数字）→ 合法
- 边界情况：长度刚好6 / 长度刚好20 / 长度5 / 长度21
- 异常情况：空字符串 / 长度5无数字 / 长度30 / None

    1、正常情况
        密码包含数字且密码的字符串长度在6-20（包含边界值）之间：输入abc1234，返回'密码合法'
    2、边界情况
        密码长度六位：输入abc123，返回'密码合法'；
        密码长度二十位：输入1234567890qwertyuiop，返回'密码合法'；
        密码长度五位：输入abc12，返回'密码应大于六位数';
        密码长度二十一位：输入1234567890qwertyuiopa，返回'密码长度应小于20位数'
    3、异常情况
        密码是空字符串：提示'请输入密码'；
        密码不包含数字：qwertyui提示'请输入含有数字的密码'；
        密码长度不符合但包含数字：qw12提示'密码应大于六位数'或'密码应小于二十位数'；
        密码长度不符合且不包含数字：qwer结合以上两者提示；
        密码是中文字符：提示'请输入英文字母和数字作为您的密码'

# 周五：内置函数、字符串处理、SQLite入门

给SQLite操作写测试清单：
- 正常情况：插入3条数据，查询返回3条 ✓
- 边界情况：空表查询 / 插入NULL值 / 价格为0
- 异常情况：表名不存在 / 列名拼写错误 / 数据库文件被占用

    1、正常情况
        插入数据：插入三条数据，查询返回三条数据；
        删除数据：有三条数据，删除其中一条数据，查询返回两条数据；
        修改数据：UPDATE books SET price=66 WHERE title="aaa"，设标题为aaa的数据原本的price为70，修改前查询该条数据price为70，修改后再查询该条数据price为66。
    2、边界情况
        插入数据库中曾经已有的数据时，如果触发主键或唯一值重复则报错，如果没有则会插入重复数据；
        给没有设定not null的字段插入null值，该条数据的该字段为空；
        给设定not null的字段插入null值，会报错；
        当查询的表内容为空时，查询返回空列表或None；
        当要删除或者更改一个空表中的数据时，不会报错。
    3、异常情况
        表名不存在；
        列名/表名/sql语句拼写错误；
        当用占位符传字段参数或数据时，占位符/参数数量对不上、数据类型不合规、拼写不合规等
