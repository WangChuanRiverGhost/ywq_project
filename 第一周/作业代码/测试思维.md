写一个猜数字游戏：程序随机生成1-100的数字，用户循环猜，
大了提示"大了"，小了提示"小了"，猜对了提示"恭喜"并退出
给上面的"猜数字游戏"写一份**测试清单**（不用写代码，写文字描述）：
- 正常情况：猜50，范围在1-100 ✓
- 边界情况：猜1（最小值）/ 猜100（最大值）/ 猜0（越界）
- 异常情况：输入"abc"（非数字）/ 输入空值 / 输入小数

    1、正常情况
        设程序生成50
        用户输入1-100内的数字时，当大于五十时输出“大了”；
        用户输入1-100内的数字时，当小于五十时输出“小了”；
        用户输入1-100内的数字时，当等于五十时输出“恭喜”，并游戏结束；
    2、边界情况
        当用户输入0或101时，应该提示超出范围而不是直接报错
    3、异常情况
        当用户输入非整数的情况下，应该提示输入整数

# 周二：函数、参数、作用域

写函数 calc_bmi(height, weight) — 计算BMI，返回BMI值和等级
    BMI = weight / (height ** 2)
    <18.5: 偏瘦, 18.5-24: 正常, 24-28: 偏胖, >28: 肥胖
    返回示例：(22.5, "正常")
给 `calc_bmi` 函数写测试清单：
- 正常情况：身高1.75，体重70 → BMI约22.86，等级"正常"
- 边界情况：BMI=18.5（正好在边界）/ BMI=24 / BMI=28
- 异常情况：身高为0 / 体重为负数 / 输入非数字

    1、正常情况：
        当身高体重计算结果符合范围内，显示bmi及其等级
    2、边界情况
        bmi在边界时显示问题
    3、异常情况
        输入不符合规定时（如单位不符合，输入非数字时）异常提醒

# 周三：异常处理

写函数 check_password(password)
    长度<6：raise ValueError("密码太短")
    长度>20：raise ValueError("密码太长")
    没有数字：raise ValueError("密码需要包含数字")
    全部通过：return "密码合法"
给 `check_password` 函数写测试清单：
- 正常情况："abc123"（长度6，有数字）→ 合法
- 边界情况：长度刚好6 / 长度刚好20 / 长度5 / 长度21
- 异常情况：空字符串 / 长度5无数字 / 长度30 / None

    1、正常情况
        密码包含数字且密码的字符串长度在6-20（包含边界值）之间：输入abc1234，返回'密码合法'
    2、边界情况
        密码长度六位：输入abc123，返回'密码合法'；
        密码长度二十位：输入1234567890qwertyuiop，返回'密码合法'；
        密码长度五位：输入abc12，返回'密码应大于六位数';
        密码长度二十一位：输入1234567890qwertyuiopa，返回'密码长度应小于20位数'
    3、异常情况
        密码是空字符串：提示'请输入密码'；
        密码不包含数字：qwertyui提示'请输入含有数字的密码'；
        密码长度不符合但包含数字：qw12提示'密码应大于六位数'或'密码应小于二十位数'；
        密码长度不符合且不包含数字：qwer结合以上两者提示；
        密码是中文字符：提示'请输入英文字母和数字作为您的密码'
