- 资料：廖雪峰教程 — "函数"章节
- 掌握要点：
  - `def` 定义函数
  - 参数和返回值
  - 函数文档字符串（docstring）：用三引号描述函数功能
  - 函数即对象：函数可以赋值给变量、作为参数传递

**2. 函数参数（今日重点）**
- 资料：Python官方教程 — 4.7 函数定义
- 必须掌握的5种参数：
  1. **位置参数**：`def func(a, b)` — 按顺序传
  2. **默认参数**：`def func(a, b=10)` — 有默认值，可省略
  3. **可变参数**：`def func(*args)` — 收集多余位置参数为**元组**
  4. **关键字参数**：`def func(**kwargs)` — 收集多余关键字参数为**字典**
  5. **命名关键字参数**：`def func(*, name, age)` — 必须用关键字传

**3. 作用域**
- 资料：菜鸟教程 — "Python作用域"
- 掌握要点：
  - 局部变量：函数内定义，函数外访问不到
  - 全局变量：函数外定义，函数内可以读取
  - `global` 关键字：在函数内修改全局变量

**4. 返回值**
- 掌握要点：
  - `return` 返回单个值
  - 返回多个值（本质是返回元组）：`return a, b, c`
  - 没有return的函数返回 `None`
  - 函数遇到return就结束执行

### 今日重点
- 彻底搞懂try/except/else/finally四段结构
- 学会raise主动抛出异常
- 了解自定义异常

### 学新知识

**1. 异常的概念**
- 资料：廖雪峰教程 — "错误处理"章节
- 理解什么是异常：
  - 程序运行时发生的错误，如果不处理会崩溃
  - 常见异常类型：
    - `ValueError` — 值错误（如int("abc")）
    - `TypeError` — 类型错误（如"abc" + 1）
    - `IndexError` — 索引越界
    - `KeyError` — 字典键不存在
    - `FileNotFoundError` — 文件不存在
    - `ZeroDivisionError` — 除零错误
    - `AttributeError` — 属性不存在

**2. try/except结构（核心）**
- 资料：Python官方教程 — 8.3 异常处理
- 必须掌握的结构：
  ```python
  # 基本结构
  try:
      # 可能出错的代码
  except ValueError as e:
      # 捕获特定异常，e是异常对象
      print(f"值错误：{e}")

  # 多个except
  try:
      ...
  except ValueError:
      print("值错误")
  except TypeError:
      print("类型错误")
  except Exception:  # 兜底
      print("其他错误")

  # else 和 finally
  try:
      ...
  except ValueError:
      print("出错时执行")
  else:
      print("没出错时执行")
  finally:
      print("无论是否出错都执行")  # 常用于清理资源
  ```

**3. raise主动抛出异常**
- 掌握要点：
  - `raise ValueError("不能为空")` — 主动抛出
  - 在函数中判断条件不满足时抛异常
  - 这是自定义函数校验参数的标准做法

**4. 自定义异常**
- 资料：Python官方教程 — 8.5 用户定义的异常
- 了解即可：
  ```python
  class MyError(Exception):
      def __init__(self, message):
          self.message = message
  ```

## 周四（10月15日）：列表、字典、模块、虚拟环境

### 今日重点
- 搞懂 `if __name__ == '__main__'` 的含义
- 列表和字典的常用操作
- 学会虚拟环境与pip管理

### 学新知识

**1. 列表与字典**
- 资料：廖雪峰教程 — "list和tuple" / "dict"
- 列表重点操作：
  - 增：`append()`、`insert()`、`extend()`
  - 删：`remove()`、`pop()`、`del`
  - 改：`lst[index] = value`
  - 查：`lst.index()`、`lst.count()`、`in`
  - 排序：`sort()`、`sorted()`
  - 切片：`lst[start:stop:step]`
- 字典重点操作：
  - 增/改：`d[key] = value`
  - 删：`del d[key]`、`d.pop(key)`
  - 查：`d.get(key, default)`、`key in d`
  - 遍历：`d.keys()`、`d.values()`、`d.items()`

**2. 元组与集合**
- 元组：不可变序列，`t = (1, 2, 3)`
- 集合：无序不重复，`s = {1, 2, 3}`，交集`&`、并集`|`、差集`-`

**3. 模块与包**
- 资料：Python官方教程 — 6 模块
- 掌握要点：
  - `import 模块名` — 导入整个模块
  - `from 模块名 import 函数名` — 导入特定内容
  - `from 模块名 import *` — 导入全部（不推荐）
  - `import 模块名 as 别名` — 起别名
  - **核心知识点：`if __name__ == '__main__'` 的含义**
    - 模块被直接运行时，`__name__` 的值是 `'__main__'`
    - 模块被导入时，`__name__` 的值是模块名
    - 作用：让模块既能被导入使用，又能直接运行做测试

**4. 虚拟环境与pip**
- 资料：廖雪峰教程 — "虚拟环境"
- 实操步骤：
  ```
  python -m venv venv          # 创建虚拟环境
  venv\Scripts\activate        # 激活（Windows）
  pip install requests          # 安装第三方库
  pip list                      # 查看已安装的包
  pip freeze > requirements.txt # 导出依赖清单
  pip install -r requirements.txt  # 从清单安装
  deactivate                    # 退出虚拟环境
  ```

### 今日重点
- 补上常用内置函数（map、filter、zip、enumerate等）
- SQLite基础操作，为周六项目做准备

### 学新知识

**1. 常用内置函数**
- 资料：Python官方文档 — 内置函数
- 必须掌握：
  - `len()` — 求长度
  - `range(start, stop, step)` — 生成数字序列
  - `enumerate(iterable)` — 同时获取索引和值：`for i, v in enumerate(lst)`
  - `zip(a, b)` — 同时遍历多个序列
  - `map(func, iterable)` — 对每个元素应用函数：`list(map(str, [1,2,3]))` → `['1','2','3']`
  - `filter(func, iterable)` — 过滤：`list(filter(lambda x: x>0, [-1,0,1,2]))` → `[1,2]`
  - `sorted(iterable, key=, reverse=)` — 排序
  - `sum()` / `max()` / `min()` / `abs()` / `round()`
  - `any()` — 有一个True就返回True / `all()` — 全部True才返回True

**2. 字符串处理**
- 资料：菜鸟教程 — "Python字符串"
- 掌握要点：
  - 切片：`s[start:stop:step]`
  - 格式化：
    - f-string（推荐）：`f"{name}今年{age}岁"`
    - `.format()`：`"{}今年{}岁".format(name, age)`
  - 常用方法：
    - `split(sep)` — 分割
    - `join(iterable)` — 拼接：`"-".join(["a","b","c"])` → `"a-b-c"`
    - `strip()` — 去首尾空格
    - `replace(old, new)` — 替换
    - `upper()` / `lower()` — 大小写转换
    - `startswith()` / `endswith()` — 判断开头/结尾
    - `find()` / `index()` — 查找

**3. SQLite入门**
- 资料：菜鸟教程 — SQLite教程
- SQLite是用文件存储的轻量数据库，不需要安装服务
- Python内置 `sqlite3` 模块，无需安装
- 核心操作步骤：
  ```python
  import sqlite3

  # 1. 连接数据库（文件不存在会自动创建）
  conn = sqlite3.connect("test.db")

  # 2. 创建游标
  cursor = conn.cursor()

  # 3. 创建表
  cursor.execute("""
      CREATE TABLE IF NOT EXISTS students (
          id INTEGER PRIMARY KEY AUTOINCREMENT,
          name TEXT NOT NULL,
          age INTEGER,
          score REAL
      )
  """)

  # 4. 插入数据
  cursor.execute("INSERT INTO students (name, age, score) VALUES (?, ?, ?)",
                 ("小明", 18, 95.5))

  # 5. 查询数据
  cursor.execute("SELECT * FROM students")
  rows = cursor.fetchall()
  for row in rows:
      print(row)

  # 6. 更新数据
  cursor.execute("UPDATE students SET score = ? WHERE name = ?",
                 (100, "小明"))

  # 7. 删除数据
  cursor.execute("DELETE FROM students WHERE name = ?", ("小明",))

  # 8. 提交事务（增删改必须commit）
  conn.commit()

  # 9. 关闭连接
  conn.close()
  ```
