# 周四（10月15日）：列表、字典、模块、虚拟环境

### 一、列表
    - 列表是一种有序的集合，是python数据类型，可以被改动。
    - 获取列表长度：len(list)
    - 索引：list[num] 
        - 可以通过索引去替换列表中对应位置的元素
        - 当索引值超出list（本身长度-1）时，会出现“索引越界”错误；
        - 索引值可以为任意整数
    - 列表常见操作：
        - 增加append()；删除元素remove()；删除指定/最后一个元素pop()
### 二、元组
    - 元组是一种有序的集合，是python数据类型，不可以被改动；元组内的元素是确定的，定义之后不可改变；但当元组内的元素A本身可以被改变时（如列表），可以改变元素A，但只是改变A而非该元组本身。
### 三、字典
    - 字典是一种查询效率极快的储存数据的方式，由键值对组成，其中，当字典被创建后，字典的键无法被修改。
    - 当要判断字典中的键是否存在时，可以用in或者get；其中，get也可以返回当键不存在时返回的值。
    - 比起列表，字典占用的空间大，但查询速度比列表快。
### 四、集合
    - 集合是一个无序的，只储存key的储存数据的方式。
    - 可以通过set(list)将有序列表转换为无序集合。
    - 集合常见操作：
        - 删除元素remove()；添加元素add()
### 五、模块
    - 1、模块概述
    - 私有符号表：名字->对象的映射表
    - 简单来讲，模块中有顶层可执行语句，其中的函数/类定义执行时会创建函数对象/类对象并绑定名字；通常来说模块是一个.py文件，但也会有.pyd/内置模块等。
    - 可以通过 import 模块名、from 模块名 import 函数名、from 模块名 import * 导入模块；import * 会导入该模块中的所有不以_开头的顶层名字。
    - 当模块被调用，且在同一个python进程内，有且仅有一次模块初始化，会执行可执行语句以及创建被定义的函数对象或类对象；在这个过程中创建的对象，将被加入该模块的私有符号表；每个模块都有自己的私有符号表，每个模块的私有符号表天然隔离、互不影响；如果需要访问另一个模块的内容，必须通过modname.itemname，但其在命名空间层面是隔离的，即变量名不互通，a.py导入了b.py，它们都有x，但指向的对象不同。而对于指向的对象可能共享，如b中有一列表data，在a中对b的data列表更改会影响data指向的对象。
    - 当这个模块中的函数需要调用这些对象时，对于函数来说，这些私有符号表中的对象是它们的全局命名空间，且优先级遵循legb，局部命名空间内的对象优先级高于它们。
    - 引入新模块时，python会自动检查sys.modules字典，查找这个新模块是否已存在且初始化完成；为了初始化以及调用引入的模块，需要查找它们的位置。首先查找的是内置模块，其次是sys.path。在sys.path中，最先查询脚本/当前所在目录，其次是pythonpath中的目录，其次是标准库目录，最后是第三方包。
    - 每一个模块都有__name__属性。当被import时，name的值是模块名，被直接运行时，name的值是__main__；当当前启动文件是自身，即__name__ = __main__时，执行该代码块中的语句。常用于测试该文件。
    - python是一种先把源码编译成中间形式，再由python虚拟机解释执行的语言。为了防止每次加载python进程都进行编译，python提前把编译结果储存在__pycache__文件夹里，并在每次调用时检查其中的编译版本和文件的修改日期来决定pycache文件夹里面的编译结果是否过期，是否需要更新。需要的话，重新编译py文件。
    - 从命令行直接载入的模块每次都会重新编译且不储存编译结果；当编译结果pyc文件没有源模块时，不会检查缓存。
    - pyc文件的加载速度更快。但执行速度与其他文件相同。
    - 2、python标准库
    - python标准库指无需pip安装即可import使用，是python在安装时内置的模块。
    - 不是所有标准库都在所有平台上都存在，如winreg只在windows系统上有；但sys全平台都有，因为sys用来访问和操控python解释器本身。
    - 有一些python标准库被直接编译在python解释器内部，被称为内置模块，运行速度更快，如sys；其他的模块是普通标准模块，是py文件。
    - 3、dir()函数
    - dir函数用于查看对象内部的名字列表。
    - 当dir()中没有参数时，显示当前命名空间中的所有名称；当dir()中有参数时，显示参数对象的命名空间中的名称。
    - 用dir()查看内置函数和名称时，如print,int。需要配合builtins模块查看：dir(builtins)（前提是import了builtins）

### 六、包
    - 当一个目录包含__init__.py文件时，python就认为这个目录是一个包。
    - 当导入一个包时，会执行其中的__init__.py进行包的初始化。
    - 可以通过import 包名.文件夹.模块的格式导入一个包，但调用时需要写整个名字；可以通过from 包名.文件夹(.模块) import x 导入一个模块或函数（x为模块或函数名），当导入的是模块时，调用其中的函数需要 模块名.函数名()；当导入的是函数时，可以直接通过函数名()调用。
    - 当使用 from 包.包/模块 import * 时，并不会导入这个包或模块中的所有函数，并且会花费很长时间。当包的创作者认为或许使用者会用from .. import *时，可以在__init__.py中使用__all__，用来定义一个名称列表。当from .. import *被调用时，会初始化__init__.py，并执行__all__，通过all中定义的名称列表，去寻找该包或模块中这些名称指向的对象。但是，当名称中存在init包含的名称时，会覆盖真实想要指向的对象名称，因为对于all来讲，这个是内部的，而真正要指向的是外部的命名空间。
    - 但当__all__不存在时，该语句不会导入任何模块或函数，只是确保该包已经被导入。所以通常来讲不会用import*导入包。
    - 绝对导入是把包的路径完整的写出来；相对导入通过from . import 名称来导入目标，其中,"."是导入目标的前面所有的路径；python通过__package__来解析.。
### 七、虚拟环境
    - 当项目中需要使用环境隔离时，使用虚拟环境进行环境隔离，同时也能保证环境干净。

        - 1、创建运行虚拟环境的目录
        - 2、创建venv python3 -m venv .
    - 进入虚拟环境：
        - 1、进入bin目录
        - 2、source activate激活虚拟环境
    - 在虚拟环境中用pip install安装需要的包
