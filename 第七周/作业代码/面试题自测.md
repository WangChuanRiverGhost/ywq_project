# 周三（11 月 25 日 · 上午）：MySQL 基础 · 命令行 + 可视化工具（day28）
### 1. MySQL 怎么连接？你用的什么工具？
命令行敲mysql -u用户名 -p密码（如果有）；  
mysql/XAMpp
### 2. 数据库、表、行的关系是什么？
库储存表，表里包含行，行需要遵守表的列（即字段）的要求
### 3. `SELECT * FROM users WHERE id = 1` 这句 SQL 是做什么的？
查询id=1的所有字段的数据
### 4. 什么是 PRIMARY KEY？为什么要 AUTO_INCREMENT？
PRIMARY KEY是主键，是唯一标识每一条数据的字段；  
AUTO_INCREMENT是自增长，通常用在被设为主键的id字段中，用于每插入一条数据就增加一个数，避免手动维护编号带来的复杂性
### 5. 你之前学的 SQLite 和 MySQL 有什么区别？
sqlite是本地的数据库，无需联网，针对单用户；  
MySQL是一个数据库服务，需要联网，可以满足多用户的需求。

# 周三（11 月 25 日 · 下午）：SQLAlchemy 连接 MySQL + 创建 engine（day29）
### 1. SQLAlchemy 是什么？ORM 是什么意思？
SQLAlchemy是python中的一个ORM框架，提供用python语言操作数据库的方式；  
ORM是一种将面向对象中的类与数据库中的表直接映射的技术
### 2. SQLAlchemy 里 engine、Session、Base 分别起什么作用？
engine是创建数据库连接，需要对数据库进行连接才有后续的操作；  
Base是ORM基类，需要继承自DeclarativeBase，才可以将表转换为python中可操作的对象。后续其他表需要继承自Base；  
Session用于创建数据库会话session来进行数据增删改查操作，并用来管理事务
### 3. `mysql+pymysql://root:@localhost:3306/xxx` 这个连接字符串每个部分是什么意思？
mysql是连接的数据库；  
pymysql是数据库连接驱动；  
root是用户名，root冒号后跟密码；  
@localhost:3306是MySQL服务地址，这里指在本机的3306端口；  
xxx是要连接的数据库名
### 4. SQLite 和 MySQL 切换时，SQLAlchemy 代码要改什么？
连接的数据库服务名称，数据库服务地址要从本机3306端口换成sqlite的文件路径
