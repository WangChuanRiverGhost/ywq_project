### A2. 修路由双前缀 bug

现在 `APIRouter(prefix="/users")` 配 `@router.post("/users")`，实际路径变成了 `/users/users`。

- [ ] 打开 `项目/用户管理系统/routers/users.py`
- [ ] 所有 `@router.post("/users")` / `@router.get("/users")` 之类的路径改成对应短路径：注册改 `"/register"`、登录改 `"/login"`、个人中心改 `"/my-account"`
- [ ] `routers/todos.py` 同样处理：`@router.post("/todos")` → `@router.post("")`，其余按语义改

**验收标准：** 启动后打开 `http://127.0.0.1:8000/docs`，接口路径显示为 `/users/register`、`/users/login`、`/todos/`，**不再是** `/users/users/...`。

> **`/docs` 是什么：** FastAPI 启动后会自动生成一个接口文档 + 调试页面，地址固定是 `http://127.0.0.1:8000/docs`。页面上列出你写的所有接口，每个接口右边有 **Try it out** 按钮，点开填参数、点 Execute 就能直接发请求、看到返回的 JSON 和状态码，不用装 Postman。
