# mysql
重要：命令打完后要有英文分号
mysql是一种服务端数据库。  
从大到小，其组成大致可以看为：库|表|数据。  
其中，库是最大的单位，其中包括表（表有结构，包含我们期望的数据字段），表中存在数据。
## 库
库是最大的单位。在mysql中，以用户为单位对库进行管理。每个用户因为权限不同，能看到的库和进行的库操作也不同。  
对于普通用户来说，有以下三种操作库的方式：
```mysql
CREATE DATABASE aaa  # 建库
SHOW DATABASE  # 查看库
USE aaa  # 进入库
```
其中，进入库是一切对于指定表/指定数据操作的前提
## 表
进入库后，可以在库中进行表/数据操作。  
其中，关于表操作有以下：
```mysql
CREATE TABLE table_name()  # 建表
DROP TABLE table_name  # 删表
ALTER TABLE table_name  # 改表
```
对于建表，实际上是创建一个表并添加期望的字段，可以对字段添加约束（如主键、外键、自增长、非空等）  
建表后，添加的字段决定了表的结构，实际的数据要根据表的结构来填写
## 数据
对于表中的数据，有以下几种操作方式：
```mysql
INSERT INTO table_name(column1,column2,column3...) VALUE(value1,value2,value3...)  # 添加数据
DELETE FROM table_name  # 删除数据
UPDATE table_name SET old_column1=new_column1  # 更改数据（实际上修改的是字段的值，可以加where子句）
SELECT * FROM table_name  # 查询数据（*可以改成指定字段，表名后可以加where子句）
```
