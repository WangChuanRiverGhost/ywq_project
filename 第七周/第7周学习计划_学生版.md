### 学新知识

**1. SQLAlchemy 是什么**

SQLAlchemy 是 Python 里最常用的 **ORM 框架**。ORM = Object-Relational Mapping = 把 Python 类映射成数据库表，把 Python 对象操作翻译成 SQL 语句。

比如：
- Python 里写 `db.query(User).filter(User.username == 'admin').first()` → SQLAlchemy 翻译成 `SELECT * FROM users WHERE username = 'admin' LIMIT 1;`
- Python 里写 `db.add(new_user)` + `db.commit()` → SQLAlchemy 翻译成 `INSERT INTO users ...; COMMIT;`

**好处：** 不用手写 SQL 了，用 Python 的方式操作数据库，而且换数据库（从 MySQL 换成 PostgreSQL）几乎不用改代码。

**2. SQLAlchemy 4 个核心概念**

| 概念 | 作用 | 项目里的位置 |
|---|---|---|
| `engine` | 数据库连接（MySQL / SQLite / PostgreSQL） | `database.py` |
| `SessionLocal` | 会话（和数据库交互的"窗口"） | `database.py` |
| `Base` | ORM 模型的基类（所有模型都继承它） | `database.py` |
| `Model` | 数据库表对应的 Python 类 | `models/` 目录 |

### 动手写代码

### 学新知识

**ORM 模型 = Pydantic 模型的"数据库版"**

你之前在 `schemas/user.py` 里写了 Pydantic 模型（用来校验请求体），今天在 `models/` 里写 SQLAlchemy ORM 模型（用来操作数据库）。两者长得像但**用途不同**：

| 对比 | Pydantic 模型（schemas/） | SQLAlchemy 模型（models/） |
|---|---|---|
| 用途 | 校验接口请求/响应 | 操作数据库表 |
| 继承自 | `BaseModel` | `Base`（database.py 里的） |
| 字段 | 类型标注 + 默认值 | Column() + 类型 + 约束 |
| 位置 | `schemas/user.py` | `models/user.py` |

### 动手写代码

**1. `models/user.py`（User 数据库模型）**

```python
from sqlalchemy import Column, Integer, String, DateTime
from sqlalchemy.sql import func
from database import Base

class User(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True, index=True, autoincrement=True)
    username = Column(String(50), unique=True, index=True, nullable=False)
    hashed_password = Column(String(255), nullable=False)
    email = Column(String(100), nullable=True)
    created_at = Column(DateTime(timezone=True), server_default=func.now())
```

**2. `models/todo.py`（Todo 数据库模型）**

```python
from sqlalchemy import Column, Integer, String, Boolean
from database import Base

class Todo(Base):
    __tablename__ = "todos"

    id = Column(Integer, primary_key=True, index=True, autoincrement=True)
    title = Column(String(200), nullable=False)
    done = Column(Boolean, default=False)
    user_id = Column(Integer, nullable=True)  # 以后关联用户，本周先不搞外键
```

**3. `models/__init__.py`（让 Base 知道有哪些模型）**


- 把 CRUD 操作封装成独立函数（`crud.py`）
- 为明天"项目数据层切换"做好准备
- Git 每日提交

### 学新知识

**SessionLocal 是什么**——每次和数据库交互都要先创建一个 Session，用完关闭。标准用法：

```python
from database import SessionLocal

db = SessionLocal()
try:
    # 在这里做数据库操作
    ...
finally:
    db.close()
```

**四种 ORM 操作的写法（记住这四句话就行）**

| 操作 | 代码 | SQL 对应 |
|---|---|---|
| **增** | `db.add(obj)` + `db.commit()` + `db.refresh(obj)` | `INSERT INTO ...; COMMIT;` |
| **删** | `db.delete(obj)` + `db.commit()` | `DELETE FROM ... WHERE id = ?; COMMIT;` |
| **改** | `db.query().filter().update()` + `db.commit()` | `UPDATE ... SET ... WHERE ...; COMMIT;` |
| **查（单条）** | `db.query(User).filter(User.id == 1).first()` | `SELECT * FROM users WHERE id = 1 LIMIT 1;` |
| **查（多条）** | `db.query(Todo).filter(...).all()` | `SELECT * FROM todos WHERE ...;` |

> 注意：`db.commit()` 之后如果还要拿到刚操作完对象的最新状态，要调 `db.refresh(obj)`。比如刚 add 了新用户，它的 id 是数据库生成的，commit 之后要 refresh 才能拿到。

### 动手写代码

新建 `crud.py`（CRUD 函数集中在这里，路由层调这些函数）：

```python
from sqlalchemy.orm import Session
from models import User, Todo

# ========== User CRUD ==========

def get_user_by_username(db: Session, username: str):
    """按用户名查（注册时查重、登录时验证都用这个）"""
    return db.query(User).filter(User.username == username).first()

def create_user(db: Session, username: str, hashed_password: str, email: str = None):
    """创建新用户"""
    new_user = User(username=username, hashed_password=hashed_password, email=email)
    db.add(new_user)
    db.commit()
    db.refresh(new_user)  # 拿到数据库生成的 id 和 created_at
    return new_user

# ========== Todo CRUD ==========

def get_all_todos(db: Session, skip: int = 0, limit: int = 50):
    """查所有待办（分页）"""
    return db.query(Todo).offset(skip).limit(limit).all()

def get_todo_by_id(db: Session, todo_id: int):
    """按 id 查某一条"""
    return db.query(Todo).filter(Todo.id == todo_id).first()

def create_todo(db: Session, title: str, done: bool = False, user_id: int = None):
    """新增待办"""
    new_todo = Todo(title=title, done=done, user_id=user_id)
    db.add(new_todo)
    db.commit()
    db.refresh(new_todo)
    return new_todo

def update_todo(db: Session, todo_id: int, title: str = None, done: bool = None):
    """修改待办（可以只改 title 或只改 done 或都改）"""
    todo = get_todo_by_id(db, todo_id)
    if not todo:
        return None
    if title is not None:
        todo.title = title
    if done is not None:
        todo.done = done
    db.commit()
    db.refresh(todo)
    return todo

def delete_todo(db: Session, todo_id: int):
    """删除待办"""
    todo = get_todo_by_id(db, todo_id)
    if not todo:
        return None
    db.delete(todo)
    db.commit()
    return todo
```

```python
print(f"✅ 查所有 todo：共 {len(all_todos)} 条")

# 删除

```

### 动手改代码（核心！）

**第一步：把 routers 里的内存数据库清掉**

删除 `routers/users.py` 里的：
```python
users_db = []  # 删掉这行
```

删除 `routers/todos.py` 里的：
```python

```

**第二步：在 routers 里导入 db session 和 crud 函数**

`routers/users.py` 顶部加：
```python
from fastapi import Depends, HTTPException
from database import SessionLocal

```

`routers/todos.py` 顶部加：
```python
from fastapi import Depends, HTTPException
from database import SessionLocal
from crud import get_all_todos, get_todo_by_id, create_todo, update_todo, delete_todo
```

**第三步：写一个 get_db 依赖（所有路由都要用）**

`routers/users.py` 和 `routers/todos.py` 里都加：
```python
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**第四步：改写每个路由函数（以 users 注册为例）**

```python
@router.post("/register")
def register(user: UserCreate, db = Depends(get_db)):  # 注意：加了 db 参数
    # 1. 用户名查重（之前用 users_db 列表查，现在用 crud 函数查）
    if get_user_by_username(db, user.username):
        raise HTTPException(status_code=400, detail="用户名已存在")
    
    # 2. 密码加密（和之前一样）
    hashed = hashlib.sha256(user.password.encode()).hexdigest()
    
    # 3. 创建用户（之前 users_db.append()，现在调 crud.create_user）
    new_user = create_user(db, user.username, hashed, user.email)
    
    # 4. 返回
    return {"id": new_user.id, "username": new_user.username}
```

**类似地改写登录接口、待办 CRUD 接口**——把每个 `users_db.xxx()` / `todos.xxx()` 替换成调 crud 函数。

**第五步：跑起来测试**

```bash
uvicorn main:app --reload
```

然后在 Swagger 里跑完整流程：
```
注册 → 登录 → 新增待办 → 查所有 → 修改 → 删除
```
