# 周一：Pydantic 深入 · 模型继承 · 字段校验
### 1. Pydantic 是什么？在 FastAPI 里起什么作用？
pydantic是一个校验框架，负责自动检测数据是否合法（符合类型）以及进行类型转化、多场景数据定义等
### 2. 注册、登录、数据库存储为什么要用不同的 Pydantic 模型？
使数据独立分离，不需要用到某数据的场景不接触到该数据（如密码），更加安全
### 3. FastAPI 参数校验失败返回什么状态码？
422
### 4. 你学过的 dataclass 和 Pydantic 有什么关系？
没有直接关系，是同一功能的两种实现方式。但dataclass的功能相对来讲更少一点，pydantic可以单向兼容dataclass。两者可以在同一项目的不同场景配合使用。

# 周二：APIRouter分层 · 项目目录
### 1. APIRouter 是什么？为什么要用它？
路由拆分方案。当一个项目中模块变多时，可以通过不同的路由模块实现不同的功能接口，再统一注册到app实例上。一方面分路由比较直观和方便管理，另一方面同一功能的接口可以做到复用，在不同的app实例上用相同的接口。
### 2. `prefix` 和 `tags` 参数分别起什么作用？
prefix是自动在所有路由前加指定前缀，tags是在swagger页面显示的标签名
### 3. FastAPI 项目一般怎么组织目录结构？
接口api，接收http请求、数据传输对象，定义传输的数据对象、业务逻辑，写具体的处理数据的方式让API调用，调用crud操作、数据访问，写数据的crud具体逻辑、数据模型，定义数据库模型。
### 4. Pydantic 模型和数据库模型有什么区别？
Pydantic主要定义某一类在内存中的数据并自动进行数据校验，属于api层面的数据模型，数据库模型主要定义表并进行数据库操作，属于crud层/业务逻辑层的数据模型

### 1. 为什么密码不能明文存？你用什么方式加密？
明文存密码不安全，数据库如果泄露，意味着用户密码被暴露；且拥有数据库查看权限的人都可以看到用户账密。

### 2. Pydantic 的 `response_model` 参数起什么作用？
参数过滤。实际使用时，创建一个返回的、不包含密码的pydantic对象，fastapi会自动检验返回给前端的对象是否符合该模型。
