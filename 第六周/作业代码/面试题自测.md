# 周一：Pydantic 深入 · 模型继承 · 字段校验
### 1. Pydantic 是什么？在 FastAPI 里起什么作用？
pydantic是一个校验框架，负责自动检测数据是否合法（符合类型）以及进行类型转化、多场景数据定义等
### 2. 注册、登录、数据库存储为什么要用不同的 Pydantic 模型？
使数据独立分离，不需要用到某数据的场景不接触到该数据（如密码），更加安全
### 3. FastAPI 参数校验失败返回什么状态码？
422
### 4. 你学过的 dataclass 和 Pydantic 有什么关系？
没有直接关系，是同一功能的两种实现方式。但dataclass的功能相对来讲更少一点，pydantic可以单向兼容dataclass。两者可以在同一项目的不同场景配合使用。
