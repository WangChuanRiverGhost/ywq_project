# SQLAlchemy ORM模型
## 安装与导入
安装：
```py
pip install sqlalchemy
# 用mysql需要安装
pip install pymysql
```
导入：
```py
# 导入数据库连接引擎、字段类型
from sqlalchemy import create_engine, Column, Integer, String, DateTime
# 导入 ORM 基类（所有模型类必须继承）
from sqlalchemy.ext.declarative import declarative_base
# 导入会话工厂（操作数据库的入口）
from sqlalchemy.orm import sessionmaker
# 可选：导入时间模块，用于设置默认时间
from datetime import datetime
```
## 使用流程
### 一、创建数据库连接引擎
1、mysql
```py
engine = create_engine(
    "mysql+pymysql://root:123456@localhost:3306/test_db?charset=utf8mb4", # mysql+驱动：//用户名：密码@主机和端口/数据库名?字符集
    echo=True, # 打印底层执行的sql语句：把底层执行的SQL语句打印到控制台
    '''连接池：预先维护的数据库连接，程序需要时从池里借一个，用完还回去，而不是每次操作都新建TCP连接'''
    pool_size=5, # 连接池大小：连接池里常驻保持的连接数（默认是5）当并发请求在5个以内时，复用连接；超过5个创建临时连接
    max_overflow=10 # 连接池最大溢出数：最多可以创建的临时连接数量
)
```
进行mysql连接时需要确保本地mysql服务已启动且已创建对应的数据库
2、sqlite
```py
engine = create_engine("sqlite:///test.db",echo=True)
```
### 二、创建ORM基类
```py
class Base(DeclarativeBase):
    pass
```
### 三、定义ORM模型（一个模型对应一张数据库中的表）
1、继承Base基类  
2、定义`__tablename__`属性（指定映射的数据库表名）  
3、至少定义一个主键字段
```py
class User(Base):

    __tablename__ = "users" # 指定表名

    # 定义字段：字段名 = Column(字段类型，约束条件)
    id = Column(Integer，primary_key=True,autoincrement=True,comment="用户id（主键，自增）")
```
#### 字段类型：
|名称|含义|
|:---:|:---:|
|Integer|整数|  
|String|字符串|  
|Text|长文本|
|Boolean|布尔|  
|DateTime|日期时间|  
|Date|日期|  
|Float|浮点数|  
|Numeric|精确小数|  
|JSON|JSON|  
|Enum|枚举|  
#### 约束条件
|约束|作用|意义|
|:---|:---|:---
|primary_key=True|主键|唯一标识每一条记录的字段|
|autoincrement=True|自增|每添加一条数据自动递增生成数值|
|nullable=False/nullable=True|非空/可为空|该字段不能为空/可以为空|
|unique=True/UniqueConstraint(...)|单列/多列唯一约束|表中某一列或多列中的所有值都是唯一的|
|CheckConstraint("约束条件",name="")|检查约束|约束条件不满足时会报错，且数据不会进入数据库。约束条件是一个判断条件，name是给该约束起名|
|default=18/bool|默认值|插入数据时如果没有给该字段赋值，会自动填default的值|
|default=datetime.now|插入时自动获取时间|插入新纪录时如果没有给时间值，自动生成当前时间|
|onupdate=datetime.now|更新时自动获取时间|该条记录被修改时，自动填充修改时间|
|ForeignKey(表名.字段)|外键|外键约束
|ondelete="RESTRICT"/onupdate="CASCADE"|删除父表时限制/更新父表时级联|删除父表记录时，如果还有子表引用它，拒绝删除/更新父表被引用键时，子表外键跟着更新
|Index(...)|普通/联合索引|
|String(int)|长度限制|
|Numeric(10,2)|精确小数|
|comment=|字段注释|字段的含义
|{"comment":""}|表注释|
### 四、创建数据库表
通过Base基类的metadata.create_all(engine)方法，自动根据模型类，在数据库中创建对应的表。
```py
Base.metadata.create_all(engine)
```
### 五、创建会话
创建一个数据库操作会话session来进行增删改查操作，并且session负责管理事务。
```py
Session = sessionmaker(bind=engine)  # 创建会话工厂（绑定引擎）
sesion = Session()  # 创建一个会话实例
```
### 六、CRUD操作（通过第五步的session完成）
通过第三步的ORM模型创建实例的基础上来进行增删改查操作
#### 新增数据
有两种添加方式：
```py
user1 = User()
session.add(user1) # 单条数据添加到会话

user2 = User()
user3 = User()
session.add_all([user2,user3]) # 多条数据批量添加到会话

session.commit()
```
#### 查询数据
```py
all_users = session.query(User).all() # 查询所有数据

user = session.query(User).filter(User.name=="张三").first() # 返回第一个匹配的对象，没有则返回none

from sqlalchemy import and_, or_
users = session.query(User).filter(and_(User.age > 20, User.name != "张三")).all() # 多条件查询
```
#### 修改数据
先获取（查询）需要修改的对象，再修改对象属性，最后提交事务
```py
# 接上述，设已查到user1的数据，且有年龄，年龄为20
user1.age = 26
session.commit()
```
#### 删除数据
先获取（查询）需要修改的对象，再通过session.delete( )删除，最后提交事务
```py
session.delete(user1)
session.commit()
```
### 七、提交和回滚事务
增删改操作需要在操作后提交事务  
如果操作过程中出现错误，可以回滚事务，恢复到操作前的状态
```py
try:
    session.commit()
except Exception as e:
    session.rollback()
```
### 八、关闭会话
```py
session.close()
```

# Fastapi （伪）三层架构-FBA
### 接口/展示层：
目录：api/ 路由模块  
接收http请求、调用服务、返回响应。
### 数据传输对象
目录：schemas/ Pydantic模型  
在接口层接收http请求时进行数据校验
### 业务逻辑层
目录：service/ 服务类  
向上承接API层的调用，向下编排CRUD层的数据库操作，负责业务逻辑
### 数据访问层
目录：crud/ CRUD基类与具体操作类
数据访问
### 数据模型层
目录：models/ SQLAlchemy ORM模型
# 依赖注入
__本质上__，  
依赖注入通过在api中声明（Depends(函数名)），由fastapi框架在后台自动去调用该函数，依赖函数可以通过return（没有资源需要手动清理时）返回普通数据，或者通过yield（有资源需要开启和关闭时）交出资源；fastapi会在请求结束后自动执行yield之后的清理逻辑。  
### 具体操作方式如下：  
1、在依赖函数文件中，定义被依赖的函数
```py
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```
2、在api接口文件中导入并使用
```py
from fastapi import APIRouter, Depends # 导入Depends
from db.session import get_db # 导入依赖函数

router = APIRouter()

@router.get("/users/")
def get_users(db: Session = Depends(get_db)): 

    return {"message": "查询成功"}
```
除此以外，还可以进行依赖嵌套：
```py
def aaa(db:Session = Depends(get_db)):
    return user

@router.get("/aaa")
def bbb(user:User = Depends(aaa)):
    return user
```
