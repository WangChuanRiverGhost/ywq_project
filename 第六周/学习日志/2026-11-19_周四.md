# JWT
JWT是一种开放标准，用于在各方之间以JSON对象的形式安全的传输信息。  
安装：
```cmd
pip install PyJWT
```
### JWT的组成
共有三个部分，用“.”分割，其中，前两段用Base64URL编码，可以解密，第三段用密钥验证签名  
A.B.C  
其中：  
A:header 记录算法和类型  
B:Payload 声明（用户id、过期时间等）  
C:Signatire 用密钥对前两段做的签名
## JWT如何使用？
首先，用户提交用户名和密码，服务端校验用户密码；  
然后，校验通过后，服务端生成JWT，放入用户id、过期时间等，用密钥签名返回给客户端；  
```py
import jwt

SECRET_KEY = "your-secret-key-keep-it-safe"   # 配置密钥
ALGORITHM = "HS256" # 配置算法

def create_access_token(user_id: int, expires_minutes: int = 30) -> str: # 生成JWT
    payload = {
        "sub": str(user_id), # 用户ID
        "exp": datetime.now(timezone.utc) + timedelta(minutes=expires_minutes), # 过期时间
        "iat": datetime.now(timezone.utc), # 签发时间（可选）
    }
    token = jwt.encode(payload, SECRET_KEY,algorithm=ALGORITHM)

    return token
```
在第一次登录时，需要生成一个新的JWT：
```python
# 前面是用户名和密码的校验逻辑
token = create_access_token(user.id) # 校验通过生成JWT

return {"access_token": token, "token_type": "bearer"} # 返回给客户端
```
后续，客户端的请求会带上JWT，服务端验证签名和过期时间，通过即可，无需查数据库比对。  
新增一个JWT验证函数，如果是我们期望的则返回用户信息：
```py
def decode_token(token: str) -> dict:
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return payload
    except jwt.ExpiredSignatureError:
        raise HTTPException(status_code=401, detail="token 已过期")
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=401, detail="token 无效")
```
在fastapi中加入authorization接口：
```py
from fastapi import Depends, Header

def get_current_user(authorization: str = Header(None)) -> int: # 如果没有返回异常则返回用户id
    if not authorization or not authorization.startswith("Bearer "): # 检查客户端是否传入token
        raise HTTPException(status_code=401, detail="缺少 token")
    token = authorization.removeprefix("Bearer ")
    payload = decode_token(token)
    return int(payload["sub"])

@app.get("/me")
def read_me(user_id: int = Depends(get_current_user)): # 依赖函数
    return {"user_id": user_id}
```
