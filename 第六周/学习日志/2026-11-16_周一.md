# Pydantic
## 数据类
数据类是`@dataclass`装饰器提供的一种 主要用于存储数据 的类结构，会自动生成`__init__` `__repr__`等方法，减少代码量并提升可读性。
```python
from dataclasses import dataclass

@dataclass
class Student:
    name:str
    age:int
    gender:str
```
## field函数
在上述代码中，用以下方法使用field函数：
```python
from dataclasses import dataclass,field

@dataclass
class Student:
    name:str
    age:int = field(default=30)
    gender:str
```
### field参数
#### 默认值 default
设置该字段默认值；  
#### 默认工厂 default_factory 
由于类属性在类被定义时就在内存中分配了地址，并且会被所有实例共享（即所有实例拿到的是同一个引用），那么就存在一个问题：  
想要两个实例的同一参数互相独立，但实际上它们却指向了同一个可变对象。  
为了解决这个问题，在声明dataclass的可变默认值时，不能直接传入对象本身，而是传入一个函数（field）。这样在每次实例化时，就会动态执行这个函数，重新在堆内存中开辟一块空间，生成一个全新的可变对象，从而保证各个实例的数据互不干扰。
```py
from dataclass import dataclass,field

@dataclass
class Student:
    name:str
    age:int
    gender:str
    score:list = field(dafault_factory=list)
```
#### 排除字段 init=False
当我们期望某字段的值不在初始化时生成时，使用init=False参数进行排除，如有需要，用`__post_init__`进行该值的计算。  
post_init：dataclasses中的一个特殊方法，会在`__init__`后自动调用。可以用于属性验证、派生属性计算、动态设置默认值等。
```py
from dataclass import dataclass,field

@dataclass
class Student:
    name:str
    age:int
    gender:str
    score:list = field(dafault_factory=list) # 分数
    average_score:int(init=False) # 平均分

    def __post_init__(self):
        num_sum = 0
        for i in self.score:
            num_sum += i
        self.average_score = num_sum / len(self.score)
```
#### 元数据 metadata
本质上metadata是一个字典，用于储存某字段的原始信息/描述信息等
```py
from dataclass import dataclass,field

@dataclass
class Student:
    name:str = field(metadata={'description':'学生名字'})
    age:int = field(metadata={'description':'学生年龄'})
    gender:str = field(metadata={'description':'学生性别'})
```
查看元数据：`__dataclass_fields__`  
`__dataclass_fields__`是在用dataclass定义一个类时创建的字典。其中，键是字段名（字符串），值是dataclasses.field对象。
```py
print(Student.__dataclass_fields__['name'].metadeta)
```
## 类型自动转换（str->int）
当字段类型是int，但传入的是数字字符串时，会自动转化为数字
```py
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int = 18
    email: str = None

user1 = User(name='19',age="19")
print(type(user1.age),user1.age)
```
输出结果：
```text
<class 'str'> 19
```
## 自动校验参数（类型）
当参数类型不符合设定的类型时，返回422：
```py
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float
    is_offer: bool = None

@app.post("/items/")
def create_item(item: Item):

    return {"message": "创建成功", "item_name": item.name, "price": item.price}
```
测试结果（附图）：
```text
INFO:     127.0.0.1:64421 - "POST /items/ HTTP/1.1" 422 Unprocessable Content
```
