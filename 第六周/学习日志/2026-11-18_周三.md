# hashlib库
python中用于哈希加密的方式
## 常见哈希算法
MD5 SHA-1 SHA-256 SHA-512 
其中，它们的主要区别是输出字节长度不同
## 创建并使用哈希对象
在期望对数据进行哈希加密时，需要先创建哈希对象并设置其加密方式，再对其设置加密的字符串：
```py
import hashlib

my_str1 = "这是一"
my_str2 = "段测试字符串"

my_strhash = hashlib.new('sha256') # 创建一个SHA256的哈希对象
my_strhash.update(my_str1.encode('utf-8')) # 追加字符串
print(f"""
当前加密字符串：{my_str1}
当前加密字符串哈希值：{my_strhash.hexdigest()}
————————————————————""")

my_strhash.update(my_str2.encode('utf-8')) # 或：my_str2.encode()/bytes(my_str2,'utf-8)
print(f"""
当前加密字符串：{my_str1+my_str2}
当前加密字符串哈希值：{my_strhash.hexdigest()}""")
```
输出：
```text
当前加密字符串：这是一
当前加密字符串哈希值：6bc0da018a1bd538602ba239960655d004f8127a3aa384ef4be6062cb2c38f0b
————————————————————

当前加密字符串：这是一段测试字符串
当前加密字符串哈希值：4f960b264fa6a65e9cdabf6d600ab520bd5a4b5636a63708b0d8228d4ef99955
```
在以上创建哈希对象时，也可以通过hashlib.加密方式()的方式创建哈希对象：
```py
hash1 = hashlib.md5(b'aaa')
hash2 = hashlib.sha1(b'aaa')
hash3 = hashlib.sha256(b'aaa')

print(f"""
md5加密aaa：{hash1.hexdigest()}
sha1加密aaa：{hash2.hexdigest()}
sha256加密aaa：{hash3.hexdigest()}""")
```
输出：
```cmd
md5加密aaa：47bce5c74f589f4867dbd57e9ca9f808
sha1加密aaa：7e240de74fb1ed08fa08d38063f6a6a91462a815
sha256加密aaa：9834876dcfb05cb167a5c24953eba58c4ac89b1adf57f28f2f9d09af107ee8f0
```
