## 周二（12 月 1 日）：BeautifulSoup 解析 HTML

### 今日重点
- 看懂 HTML 的标签、属性、class、id、层级
- 会用 `find` / `find_all` / `select` 三种方式定位元素

- 先用**本地 HTML 字符串**练熟，再碰真实网站

### 学新知识

**1. 最小 HTML 认知**

```html
<div class="news-item">
    <a href="/news/1001.html">这是一条新闻标题</a>
    <span class="date">2026-11-30</span>
</div>
```

要拿"标题"和"链接"，就是找 `div.news-item` 里面的 `a` 标签。

**2. 三种定位方式**

| 方法 | 返回 | 什么时候用 |
|---|---|---|
| `soup.find("a")` | 第一个匹配元素 | 只要一个 |
| `soup.find_all("a")` | 列表 | 要多个 |
| `soup.select("div.news-item a")` | 列表（CSS 选择器） | 结构复杂时最直观 |

**3. 取数据**

```python
tag.get_text(strip=True)   # 取文字，去掉首尾空白
tag.get("href")            # 取属性
```

**4. 防空**

页面结构随时可能变，找不到元素时 `find` 返回 `None`，直接 `.get_text()` 会报 `AttributeError`：

```python
tag = soup.find("a", class_="title")
title = tag.get_text(strip=True) if tag else ""
```

理由：简历上的项目必须"看起来是真的"。爬练习专用网站（如 quotes.toscrape.com）可以练手，但**不能作为最终项目素材**。

**2. 一个合格爬虫的最小骨架**

```python
import time
import requests
from bs4 import BeautifulSoup

HEADERS = {"User-Agent": "Mozilla/5.0 ... Chrome/120.0 Safari/537.36"}

def fetch(url, retries=3):
    for i in range(retries):
        try:
            resp = requests.get(url, headers=HEADERS, timeout=10)
            resp.encoding = resp.apparent_encoding
            if resp.status_code == 200:
                return resp.text
            print(f"第 {i+1} 次请求，状态码 {resp.status_code}")
        except requests.RequestException as e:
            print(f"第 {i+1} 次请求异常：{e}")
        time.sleep(2)
    return None

def parse(html):
    soup = BeautifulSoup(html, "html.parser")
    items = []
    for node in soup.select("你的定位表达式"):
        title_tag = node.select_one("a")
        items.append({
            "title": title_tag.get_text(strip=True) if title_tag else "",
            "url": title_tag.get("href") if title_tag else "",
        })
    return items
```

**3. 合规与礼貌（必须做到）**
- 看网站的 `robots.txt`（网址后加 `/robots.txt`），禁止抓的路径不要抓
- 每次请求之间 `time.sleep(1~2)`，不要并发轰炸
- 只抓公开数据，不抓需要登录的、不涉及个人信息
- 学习用途，不商用、不分发

## 周四（12 月 3 日）：爬虫数据写入 MySQL（含去重）

### 今日重点

- 实现**去重插入**：重复运行爬虫，数据库里不会出现重复记录

### 学新知识

**1. 表设计**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 主键自增 | |
| title | VARCHAR(255) | 标题 |
| url | VARCHAR(500) | 链接，**加唯一约束**（去重的关键） |
| source | VARCHAR(50) | 来源网站 |
| publish_time | VARCHAR(50) | 网页上的时间 |
| created_at | DATETIME | 入库时间，默认当前时间 |

**2. 去重的两种方式**

| 方式 | 做法 | 优缺点 |
|---|---|---|
| 先查后插 | `SELECT` 看 url 是否存在，不存在才 `INSERT` | 直观，但多一次查询 |
| 唯一约束 + 捕获异常 | url 加 `unique=True`，插入冲突时捕获 `IntegrityError` 跳过 | 数据库兜底，最可靠 |

**本周用第二种**，因为面试能讲"我用数据库唯一约束保证不重复"。

**3. 批量插入与提交**

```python
session.add_all(obj_list)
session.commit()        # 必须 commit，否则不入库
```

出错时要 `session.rollback()`，否则后续操作会失败。

**1. 为什么要做成接口**

爬虫脚本只是"能跑"，做成接口才"能用"——这是简历上从"写过爬虫"到"做过数据采集模块"的区别。

**2. 接口设计**

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/crawler/run` | 触发一次爬取，返回 `{total, inserted, skipped}` |
| GET | `/crawler/items` | 查询已采集数据，支持 `page`、`size`、`keyword` |

注意：`APIRouter(prefix="/crawler")` 之后，路由里写 `"/run"`，不要再写 `"/crawler/run"`（第 6 周的双前缀问题不要再犯）。

**3. 外部依赖的异常处理**

爬取依赖别人的网站，目标站挂掉时**不能**把 500 堆栈直接抛给调用方：

```python
try:
    result = run_spider()
except Exception:
    raise HTTPException(status_code=502, detail="目标网站暂时不可用，请稍后重试")
```
