## 周三（11月4日）：logging 模块

### 今日重点
- 用 logging 替换项目里的 `print`——这是"从写脚本"到"做工程"的第一步。
- 理解日志级别：`DEBUG < INFO < WARNING < ERROR < CRITICAL`。

### 学新知识

```python
import logging

logging.basicConfig(
    level=logging.INFO,                        # 只显示 INFO 及以上级别
    format="%(asctime)s [%(levelname)s] %(message)s"
)

logging.debug("调试信息，平时看不到")      # 级别太低，不显示
logging.info("程序启动了")
logging.warning("这里可能有坑")
logging.error("出错了！")
```

### 动手写代码（`2026-11-04_day16_logging.py`）

3. 配置 `filename="app.log"`，让日志同时写进文件

## 周四（11月5日）：pdb 断点调试

### 今日重点
- 告别"只会用 `print` 调试"，学会**用断点停下来看变量**。
- 掌握 `breakpoint()` 和 pdb 的几个核心命令。

### 学新知识

**1. 在代码里插断点**

```python
def buggy(a, b):
    total = a + b
    breakpoint()      # 程序跑到这里会停住，进入 pdb
    return total / 2

buggy(3, 4)
```

**2. pdb 核心命令**（停住后输入）

| 命令 | 作用 |
|---|---|
| `n` | 下一步（不进入函数内部） |
| `s` | 单步进入（会进到函数里） |
| `p 变量名` | 打印某个变量的当前值 |
| `l` | 看当前代码位置 |
| `c` | 继续运行到下一个断点 |
| `q` | 退出调试 |

### 动手写代码（`2026-11-05_day17_pdb.py`）

1. 故意写一个"结果不对"的小函数（比如求和算错、除以了错误的数）
2. 用 `breakpoint()` 断点，一步步用 `p` 看变量，找到 bug 到底出在哪一行
3. 把调试过程（你敲了哪些命令、发现了什么）记进学习日志

### 测试思维训练

思考并写下来：**断点调试和写测试，有什么区别？什么时候用哪个？**
- 断点调试：定位"问题出在哪一行"（找 bug 的过程）
- 写测试：验证"结果对不对"（防止再出错的过程）

### 面试题自测

1. pdb 断点调试主要用哪几个命令？
2. 相比你之前只会 print 调试，断点调试好在哪？

## 周五（11月6日）：pytest 入门

### 今日重点
- **正式入门 pytest——测试岗的看家本领**。前几周你一直在写"测试思维清单"，今天开始把"想法"变成"能自动跑的测试代码"。
- 会写最简单的测试函数，会用 `assert` 断言。

### 学新知识

**1. 安装**

```bash
pip install pytest -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**2. 写测试（约定：文件名 `test_` 开头，函数 `test_` 开头）**

```python
# test_calc.py
def add(a, b):
    return a + b

def test_add():
    assert add(1, 2) == 3      # 通过
    assert add(-1, 1) == 0     # 通过
    assert add(0, 0) == 0      # 通过
```

**3. 运行**

```bash
pytest -v
```

绿色 `PASSED` = 通过；红色 `FAILED` = 有 bug。

### 动手写代码（`test_calc.py`）

1. 写一个简单函数（比如 `divide`、`is_even`）
2. 给每个函数写 2~3 个 `assert` 测试
3. 跑 `pytest -v`，看到绿色通过
4. 故意改错一处，再跑，看红色失败——**体会"自动化测试"的意义：一条命令自动全测一遍**

### 测试思维训练

- 理解"自动化测试"：以前是手动一个个验证，现在是一条 `pytest` 命令自动全测。

### 面试题自测

1. pytest 的测试文件和测试函数命名有什么约定？
2. `assert` 是干什么用的？
