# 周二 迭代器+生成器复习查漏
给迭代器和生成器各写一份测试清单：  
迭代器：正常（从头遍历）、边界（到 StopIteration 停）、异常（迭代完再 next()）  
生成器：正常（next() 依次取值）、边界（取完抛 StopIteration）、异常（生成器只能用一次）
### 迭代器：
1、正常情况  
在多次调用同一实例的next方法时，从头开始按照next中的定义进行迭代和返回值  
2、边界情况  
当重新对实例使用iter方法时应该从头开始遍历；  
遍历到stopiteration的地方停止遍历  
3、异常情况  
遍历结束后没有初始化继续遍历需要抛stopiteration错误  
### 生成器：
1、正常情况  
多次调用同一生成器的next方法时，依次获取yield返回的值  
2、边界情况  
取值到stopiterstion的地方停止取值  
3、异常情况  
已经用完的生成器如果继续遍历需要抛stopiteration错误

# 周三 logging模块
思考并写下来：**日志和测试有什么关系？**
- 日志回答"程序运行时发生了什么"，测试回答"程序结果对不对"。两者互补，不冲突。  
日志记录程序运行中发生的事情并按级别分类；测试对日志进行评估。

# 周四 pdb断点调试
思考并写下来：**断点调试和写测试，有什么区别？什么时候用哪个？**
- 断点调试：定位"问题出在哪一行"（找 bug 的过程）
- 写测试：验证"结果对不对"（防止再出错的过程）
写测试用于让程序运行，并查看是否会出问题，如果出了就用断点调试找问题出现在什么地方。解决后再次用测试看是否会继续出问题。
