# 周二 迭代器+生成器复习查漏
### 1、可迭代对象和迭代器的区别？
迭代器一定是可迭代对象。  
可迭代对象实现了iter方法，迭代器实现了iter方法和next方法。  
可迭代对象使用iter方法返回一个新的迭代器，迭代器使用iter返回它本身self。
### 2、for 循环背后发生了什么（iter + next）？
通过iter创建初始的遍历实例，生成一个迭代器；再用next遍历这个被初始化的遍历实例直到抛stopiteration为止（但for循环会自动处理stopiteration）。
### 3、生成器为什么省内存？什么时候该用生成器？
生成器只在调用时生成下一个值，也就是在某时间内，每次生成一个比同样条件，用列表储存长度少的值，所以占用的内存也更少。  
当需要节省大量内存或者需要生成无限的对象的时候使用生成器。

# 周三 logging模块
### 1. logging 有哪几个级别？从低到高排一下？
debug、info、warning、error、critical
### 2. 为什么工程里要用 logging 而不是 print？
print只能打印到控制台，logging可以进行多次筛选进入文件或其他地方，并且可以在其中通过筛选器filter对日志进行修改，功能比print更多。

# 周四 pdb断点调试
### 1. pdb 断点调试主要用哪几个命令？
n执行当前行；s执行当前行，如有函数进入函数内部；q退出调试；l展示当前行周围的代码，p打印变量
### 2. 相比你之前只会 print 调试，断点调试好在哪？
在独立的命令行中进行调试，环境更干净；目标更明确而不是在一堆print结果中找；不用复杂的配置，思考某个地方需要打印什么，并且可以更方便的查看某个地方的变量的值而不用写很多打印这个变量的

# 周五 pytest入门

### 1. pytest 的测试文件和测试函数命名有什么约定？
测试文件需要以_test开头或者test_结尾；  
测试函数需要以test_开头。
### 2. `assert` 是干什么用的？
用于对函数进行测试，查看输入的值是否能输出期望值。
