# 快速回顾
### 1、可迭代对象和迭代器是一回事吗？iter() 和 next() 各自干什么？
可迭代对象是指实现了iter方法的对象。  
iter执行一个迭代器生命周期起始的初始化，next是具体每次迭代做的事情、返回值以及抛出结束迭代的错误。
### 2、生成器函数用什么关键字？它和普通函数（return）的本质区别是什么？
yield关键字。  
生成器在遇到yield时，会将状态保存在本次运行到yield语句的状态，下次运行时会接着上次状态继续运行。return后，每次调用该函数都是全新的初始状态（在传入的参数不变的前提下）
### 3、生成器表达式长什么样？和列表推导式差在哪？
(x * x for x in range(3))  
首先是写法上有差异（列表推导式是用中括号括起来的），其次是列表推导式一次会直接把计算结果都吐出来，但是生成器表达式是调用一次吐出来一个值，所以相对来说比列表推导式更省内存。

# time模块
__表现形式__  
时间戳（浮点数）、结构化时间（一个元组）、格式化字符串  
__常用语法__
```python
time.time() # 获取当前时间戳
time.localtime() # 获取当前本地结构化时间time.struct_time(tm_year=2026, tm_mon=11, tm_mday=3, tm_hour=15, tm_min=46, tm_sec=59, tm_wday=1, tm_yday=307, tm_isdst=0)

time.strftime() # 结构化时间转为字符串时间
time.strptime() # 字符串时间转为结构化时间
time.mktime() # 结构化时间转为时间戳
time.localtime() # 时间戳转为结构化时间

time.sleep(seconds) # 让程序暂停指定秒数（单位：秒）
```
