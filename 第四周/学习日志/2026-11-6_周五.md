# pytest

## 一、断言
`assert`是一个快速诊断某部分的程序结果是否符合预期的方式。  
格式是 `assert 表达式,返回信息`  
当表达式返回False时，assert会返回一个错误并截断程序。
## 二、pytest
pytest是一个自动化测试框架。其核心在于“测试用例”。
### 测试用例
测试用例本质上是一个函数或方法，但函数名需要以'test'开头。
### 用例发现
pytest识别并加载用例的过程称为用例发现。  
用例发现的过程如下：
```text
1、目录：遍历目录，排除venv和.开头文件；
2、文件：加载文件，加载以“test_”开头或者以“_test”结尾的文件；
3、类：寻找类，寻找以Test开头且没有__init__方法的类；
4、函数/方法：执行函数/方法，执行以test开头的函数/方法
```
### 启动pytest
启动pytest有两种方法。  
第一，命令行。在要进行pytest的目录中：
```cmd
PS D:\实训\学习计划> pytest
```
第二，在main文件中：
```python
import pytest

pytest.main()
```
## 三、fixtrue
fixture是一个夹具，用于进行测试用例开始前的准备以及测试用例结束后的回收工作，并且可以将参数传入测试用例。  
### 创建和请求fixtrue
创建一个fixtrue需要带有@pytest.fixture以及yield关键字。  
请求一个fixtrue需要在参数中加入fixtrue的名字。  
```python
import pytest

@pytest.fixture
def aaa():
    a = 1
    b = 2
    yield a + b
    a = 0

def test_aaa(aaa):
    x = aaa
    assert x==aaa
```
### fixture的作用域特性
在同个作用域中的fixture不会重复执行，多次被调用时只会执行一次。  
可以对@pytest.fixture(scope="...")添加一个参数指定它的共享范围。  
```text
function（默认）
class
module
session
```
## 四、mark
### 标记测试用例与-m参数
可以使用mark对测试用例进行标记：
```python
@pytest.mark.name1
def test_aaa():
    pass

@pytest.mark.name2
def test_bbb():
    pass

@pytest.mark.name1
@pytest.mark.name2
def test_ccc():
    pass
```
在命令行中加入-m参数：
```cmd
pytest -m "name1"
pytest -m "not name1"
```
支持逻辑表达式，and|or|not
### 参数化测试用例
```python
@pytest.mark.parametrize("x,y,z",[(),()])
def test_a(x,y,z):
    assert x + y == z
```
