# 周计划模板（冻结版）

> 自第 7 周起，所有周计划文档必须使用本结构。**课程变更记录写入 [07_周验收表.md](07_周验收表.md)，不出现在学生版周计划里**，也不许以标签形式插在正文标题中。

---

## 一、文档骨架

```markdown
# 第 N 周学习计划（学生版）

**日期：** X 月 X 日（周一）— X 月 X 日（周日）
**本周主题：** <一句话>
**本周目标：** <3—5 条可验收的目标>

> 本周定位说明（2—4 行，讲清这周在整个 16 周里的位置）

---

## 学习资料

### 文档（在线免费）
| 资料 | 用途 | 链接 |

### 工具准备
| 工具 | 说明 |

---

## 周一（X 月 X 日）：<主题>

### 今日重点
- 3—4 条

### 学新知识
<概念 + 最小可运行示例>

### 动手写代码（`作业代码/dayXX_主题.py`）
1. …

### 测试思维训练
> 1—2 条，围绕当天知识点

### 面试题自测
1. …

### 今日产出
- [ ] 代码 `dayXX_主题.py`
- [ ] 学习日志 `YYYY-MM-DD_周X.md`
- [ ] **Git 提交（commit + push）**

---

（周二 — 周日 重复上述结构）

---

## 周日：复盘

### 自我检查表
| 计划项 | 是否完成 | 产出物 |

### 下周预习
```

> 注意：学生版周计划**不包含**课程变更记录。本周新增/改动请写入 `07_周验收表.md` 的"课程变更记录"一节。

---

## 二、硬性规则

| 规则 | 说明 |
|---|---|
| 每日固定 7 个三级标题 | 今日重点 / 学新知识 / 动手写代码 / 测试思维训练 / 面试题自测 / 今日产出 |
| 标题用"今日重点""今日产出" | 禁止"今日核心""今日XXX版核心"等变体 |
| 不出现在标题里的版本标签 | 禁止 `【XX版新增】`、`（XX优化版）` 出现在标题 |
| 每日必须有"今日产出" | 且含代码、日志、Git 提交三项 |
| 每周必须有自我检查表 | 周日一节，可勾选 |
| 变更记录不进学生版 | 新增/改动写入 docs/07_周验收表.md 的"课程变更记录"一节 |
| 日期写全 | "11 月 25 日"，不写 "11/25" |

---

## 三、检查清单（写完周计划后自查）

- [ ] 每天的 7 个三级标题齐全且顺序一致
- [ ] 没有版本标签混进标题
- [ ] 每天都有"今日产出"，且含 Git 提交
- [ ] 代码文件名符合 `YYYY-MM-DD_dayXX_主题.py`
- [ ] 日志文件名符合 `YYYY-MM-DD_周X.md`
- [ ] 周日有自我检查表
- [ ] 学生版不含版本变更记录（已写入 docs/07）
