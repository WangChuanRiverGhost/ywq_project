# Git 规范清单（学生版）

> 给同学：这份清单只讲一件事——**规矩**。你的东西该放哪、该叫什么名、commit 该写什么、什么不能交。照着做，老师一眼就能看懂你的仓库。
> 命令具体怎么敲，另见《02_Git 提交作业操作指引（学生版）》。

---

## 一、东西放哪：现在只有三个抽屉

第 1—4 周（补基础阶段）只用三个文件夹，别的先不用建：

```
ywq_project/
├── 学习计划/            ← 老师发的计划文档
│   └── 第1周/
├── 学习日志/            ← 你每天的文字复盘
│   └── 第1周/
└── 作业代码/            ← 每天的练习代码
    └── 第1周_Python核心基础/
```

| 你要交的东西 | 放进哪 |
|---|---|
| 老师发的学习计划 | `学习计划/第1周/` |
| 每天的学习日志 | `学习日志/第1周/` |
| 每天的练习代码 | `作业代码/第1周_Python核心基础/` |
| 面试题答案 | `作业代码/第1周_Python核心基础/面试题自测.md`（本周汇总，按天追加） |
| 测试思维答案 | `作业代码/第1周_Python核心基础/测试思维.md`（本周汇总，按天追加） |
| 周项目 + 测试清单 | `作业代码/第1周_Python核心基础/`（前四周测试清单也放这） |

> 第 5 周开始做项目、第 11 周开始找工作，才会新建「项目」「测试用例」「求职材料」这几个文件夹，现在不用管。

## 二、文件叫什么名

| 类型 | 命名格式 | 例子 |
|---|---|---|
| 练习代码 | `day几_主题英文.py` | `day1_basics.py`、`day3_exceptions.py` |
| 一天多份代码 | `day几_内容.py` | `day4_math_tools.py`、`day4_main.py` |
| 面试题答案 | `面试题自测.md` | 每周一个，按天追加 |
| 测试思维答案 | `测试思维.md` | 每周一个，按天追加 |
| 学习日志 | `日期_周几.md` | `2026-10-14_周三.md` |
| 截图 | `日期_说明.png` | `2026-10-12_环境验证.png` |

> 记住两个要点：① 代码名带 `day几` 和主题，让人一眼知道哪天学的什么；② 日志名带日期和周几。另外，面试题、测试思维的答案**不要写在 `.py` 代码注释里**，单独放进 `面试题自测.md`、`测试思维.md` 两个文档。

## 三、commit 怎么写（最重要，写错会被老师点名）

格式就一句：**`类型: 第几周 说了什么`**

五种类型，背下来：

| 类型 | 什么时候用 | 例子 |
|---|---|---|
| `feat` | 交了新代码 / 新作业 | `feat: 第1周 day1 变量与循环练习` |
| `log` | 交了学习日志 | `log: 第1周 周一学习日志` |
| `plan` | 传了学习计划 | `plan: 第1周 学习计划归档` |
| `fix` | 改了之前的代码 | `fix: 第1周 day2 修正 BMI` |
| `docs` | 改了 README 等文档 | `docs: 更新 README` |

**错误示范 vs 正确示范**（一眼看懂）：

| ❌ 不能这么写 | ✅ 应该这么写 |
|---|---|
| `2` | `feat: 第1周 day1 变量与循环练习` |
| `update` | `fix: 第1周 day2 修正 BMI` |
| `Add files via upload` | `feat: 第1周 day3 异常处理` |
| `123` | `log: 第1周 周三学习日志` |

## 四、提交节奏

- **每天学完，当天交**，别攒到周末。
- 代码和日志**分开交**：代码用 `feat`，日志用 `log`。
- 一天可以交好几次，每次只交当天真正完成的东西。

---

## 五、这些东西不能交（千万别手动 add 它们）

| 别交的东西 | 为什么 |
|---|---|
| `venv/` 虚拟环境 | 又大又没用，别人装不了 |
| `__pycache__/`、`*.pyc` 缓存 | 电脑自动生成的垃圾 |
| `*.db` 数据库文件 | 会暴露你的数据，而且每次都在变 |
| `.env` 环境变量 | 里面可能有密码/密钥，绝不外传 |

> 这些已经写进 `.gitignore` 自动挡掉了，你只要别手动 `git add` 它们就行。

---

## 六、三条红线（违反任何一条都会被退回来）

1. **commit 不许写废话**：`2`、`update`、`123` 一律不行。
2. **类型用英文小写，后面跟中文**：`feat:`、`log:` 这种。
3. **当天事当天毕**：别攒到周末一次性狂交。

---

## 七、交之前，自己问三个问题

提交前花 10 秒自查：

- [ ] 放对文件夹了吗？（代码进 `作业代码/第1周_...`，日志进 `学习日志/第1周/`）
- [ ] 文件名对吗？（`day几_主题.py`、`日期_周几.md`）
- [ ] commit 写清楚了吗？（`类型: 第几周 说了什么`）

三个都打勾，再 `git push`。
