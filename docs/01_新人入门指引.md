# 新人入门指引

> 开始实训前，先按本文把环境和仓库准备好。预计 1—2 小时。

---

## 一、环境安装清单

| 工具 | 版本要求 | 用途 | 检查命令 |
|---|---|---|---|
| Python | 3.10+ | 全部课程 | `python --version` |
| Git | 任意新版 | 代码版本管理 | `git --version` |
| VS Code 或 Cursor | 新版 | 写代码 | — |
| Postman | 新版 | 接口测试 | — |
| Apifox | 新版 | 接口测试（国内平替） | — |
| MySQL 8.0 / XAMPP | 8.0 | 第 7 周起的数据存储 | `mysql --version` |
| Charles / Fiddler | 新版 | 第 5 周起的抓包练习 | — |

**Python 包镜像（国内加速）：**

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

## 二、第一次拿到仓库

```bash
git clone https://github.com/WangChuanRiverGhost/ywq_project.git
cd ywq_project
```

## 三、每天的固定流程

1. **开始前先拉取**：`git pull`（避免和别人/老师改动冲突）
2. 按当天计划的"今日产出"写文件，放在规定位置（见 [05_命名与目录规范](05_命名与目录规范.md)）
3. `git add .`
4. `git commit -m "feat: 第N周 dayXX 内容"`
5. `git push`

> 一天至少一次提交。攒几天一起补提交，会被记录为"集中补交"，验收时会扣分。

## 四、路径速查

| 要放的东西 | 放哪儿 |
|---|---|
| 当天练习代码 | `第N周/作业代码/dayXX_主题.py` |
| 当天文字复盘 | `第N周/学习日志/YYYY-MM-DD_周X.md` |
| 测试思维、面试题自测 | `第N周/作业代码/测试思维.md` / `面试题自测.md`（追加写，不新建文件） |
| 截图、抓包图 | `第N周/作业代码/` 下的图片，命名 `dayXX_说明.png` |
| 项目代码 | `项目/用户管理系统/`（**唯一位置**，不要在周目录里另建） |

## 五、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `fatal: not a git repository` | 不在仓库目录 | `cd` 到 `ywq_project` |
| `error: failed to push some refs` | 远端有更新 | 先 `git pull`，解决冲突后再 push |
| `git push` 卡住 / 连接被重置 | 网络问题 | 换网络或开代理，稍后重试 |
| `pip install` 极慢 | 未配镜像 | 执行上面的 `pip config set` |
| 端口被占用 | 8000 已有服务 | `uvicorn main:app --reload --port 8001` |
| MySQL 连不上 | 服务未启动 | 打开 XAMPP 点 MySQL 的 Start，状态变绿 |

## 六、求助顺序

1. 先看报错最后一行（Python 报错真正原因在最后）
2. 用 Cursor / AI 问："这段报错是什么意思，怎么改"
3. 还不行，带上**报错全文 + 你的代码 + 已尝试的方法**问老师
