### python 作用域与命名空间  
1、命名空间是从名称到对象的映射；  
2、不同命名空间是在不同时刻创建的，拥有不同的生命周期；  
3、一个命名空间的作用域是python代码中的一段文本区域，从这个区域可直接访问该命名空间；

### 继承
    class 子类名(父类名):
        pass  
1、可以通过以上代码块中的方式，使我们创建的新类（子类）拥有另一个类（父类）的所有功能，包括属性与方法。子类可以在父类的基础上增加新功能，或者修改父类的功能（多态）；  
2、父类可以是一个带有前缀的路径；  
3、多重继承
```python
class 子类名(Base1, Base2, Base3):
    pass
```  
一般来讲，一个子类可以同时继承很多个父类。  
当调用某属性时，理论上来讲可以按照base1（及其父类）->base2（及其父类）->base3（及其父类）的方式进行查找。  
但当情况变复杂时，如base1与base2中继承了相同的父类，那么按照以上查找机制则会进行多次重复查询，拖慢进程。所以，python采用C3线性化算法，决定搜索顺序，即MRO，再通过super()调用。  
有些时候，多重继承内部会“打架”，即base1期望在base2前执行，此时再运行多重继承会报错。  
### 私有变量（封装中隐藏实现细节，只暴露必要的接口）  
1、python中并不存在完全不能被外部访问的私有变量，但约定上，变量前加入一个下划线表示其为非公有部分，但如果一定要使用，也不会有机制防护；  
2、名称改写：当在变量前加入双下划线时，将被python内部解释器替换为_classname__spam。通常来讲，双下划线用来防止意外的名字冲突或防止使用者意外更改属性，实际上如果想要改内部的数据依旧可以通过_classname__spam的方式进行修改

### 迭代器
本质上，迭代器通过 iter(循环对象)->__next__(iter(循环对象))（循环）->StopIteration异常->raise捕捉->结束循环 运作。  
以下是一个对序列执行反向循环的迭代器（来源于python官方文档）：  
```python
class Reverse:
    """对一个序列执行反向循环的迭代器。"""
    def __init__(self, data):
        self.data = data
        self.index = len(data)

    def __iter__(self):
        return self

    def __next__(self):
        if self.index == 0:
            raise StopIteration
        self.index = self.index - 1
        return self.data[self.index]
```
```
>>> rev = Reverse('spam')
>>> iter(rev)
<__main__.Reverse object at 0x00A1DB50>
>>> for char in rev:
...    print(char)

m
a
p
s
```
### 生成器与yield关键字
1、生成器本质是一个函数；  
2、当生成器运行到yield时，函数会返回yield后的值，并将当前生成器内部变量的状态保存起来，直到下一次调用next();  
3、比起迭代器，生成器会自动添加iter、next以及自动引发StopOteration，所以生成器的写法更加简便，占用内存更少；  
4、生成器表达式：  
通常，生成器表达式必须包在圆括号里，但如果这个生成器表达式恰好是某个函数唯一的参数，python允许省略最外层括号。  
生成器表达式与列表推导式的区别在于，列表推导式被包在方括号[ ]里，当函数需要参数时，python在内存中划出一片空间，将列表推导式的结果算出来并且储存进去，然后交给函数计算；而生成器表达式是创建了一个生成器对象，当函数需要数据时，问生成器要一个数据，计算完后再要下一个。生成器表达式的好处是省内存。
### `__str__`  
str用于在打印一个实例对象时，控制打印的内容。通常来讲，str中的内容用于给用户/前台展示，从约定上来讲应该更加好看。同时存在str和repr时，print会优先执行str中返回的字符串。
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"Person({self.name}今年{self.age}岁)"

# 创建一个 Person 对象
person = Person("Alice", 30)

# 打印对象
print(person)
```  
### `__repr__`  
repr方法通常用于生成一个对象的"官方"字符串表示。通常来讲，repr用于调试和日志记录，从约定上来讲应该更加严谨，当只存在repr时，print会打印repr返回的字符串。在交互式环境（终端）直接敲变量名或使用repr()时，会触发repr方法；  
当把一个对象放到列表/元组/字典中打印时，即使同时存在str和repr，也会只打印repr返回的字符串。
```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Person(name={self.name}, age={self.age})"

# 创建一个 Person 对象
person = Person("Alice", 30)

# 打印对象的描述
print(person)
```  
在实际开发中，为了省事，如果 `__str__` 和 `__repr__` 想要输出一样的内容，我们通常只写 `__repr__`，然后在类里面加一行 `__str__` = `__repr__` 即可。这样无论是 print 单个对象，还是塞进列表里打印，都不会报错且格式统一。
