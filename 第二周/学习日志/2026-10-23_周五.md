# SQL关联查询基础：SQL JOIN
sql join用于把两个表连接起来，基于这些表之间的共同字段  
### 外键  
```SQL
FOREIGN KEY(从表约束字段) REFERENCES 主表名(主表约束字段)
```  
建立外键约束后，从表约束字段中的内容必须跟主表约束字段中的内容一样。否则为Null；  
一张表可以有多个外键约束。
### SQL INNER JOIN
```SQL
SELECT column_name(s)
FROM table1
(INNER) JOIN table2
ON table1.column_name=table2.column_name;
```  
当表1和表2的某字段名中，存储的数据相同时，返回所选列column_name(s)。  
在INNER JOIN中，ON可以被替换为WHERE。  
### SQL LEFT JOIN
```SQL
SELECT column_name(s)
FROM table1
LEFT (OUTER) JOIN table2
ON table1.column_name=table2.column_name;
```  
当table1.column_name=table2.column_name时查询表1和表2的column_name(s)字段，无论是否查询到，返回表1该字段的所有数据以及查询到的表2该字段的数据（表2没查到时返回Null）；  
返回的数据的列由SELECT后要查询的列决定；  
返回的数据的行由查询到的表2的行决定。假设同一字段，表1查到了3条数据，表2查到了4条，其中，表1一定有一条数据对应表2的两条数据（即一对多），此时最终查询结果会显示“两条一”对应表2的两条“多”；  
在LEFT JOIN中，ON不可以被替换为WHERE，因为ON是决定两表连接方式（即无论结果是否为真），WHERE是对数据进行筛选（即只保留查询到的真值）。  
### SQL RIGHT JOIN  
```SQL
SELECT column_name(s)
FROM table1
RIGHT (OUTER) JOIN table2
ON table1.column_name=table2.column_name;
```
逻辑同LEFT JOIN。  
### SQL FULL OUTER JOIN  
```SQL
SELECT column_name(s)
FROM table1
FULL (OUTER) JOIN table2
ON table1.column_name=table2.column_name;
```
on后的条件成立时，返回两表中所有查询的列，即使它们的值为空。当值为空时，显示Null。
### 对查询结果进行排序/分组：ORDER BY/GROUP BY  
```SQL
ORDER BY column1, column2, ... ASC|DESC;
```
ORDER BY是一个子句，常跟在查询结果后；  
ORDER BY后的字段是排序标准，可以为多个。当第一个字段相同时，按照第二个排序，以此类推；  
ASC为升序排列，DESC为降序排列。  
```SQL
GROUP BY column_name
```
通常来讲，GROUP BY子句用于去重或统计某一字段中不同值的其他字段的情况，如同一部门不同员工的总数等。后者通常与聚合函数（如SUM、AVG）结合使用。
