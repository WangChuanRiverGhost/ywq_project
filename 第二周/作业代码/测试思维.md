# 周三：类与对象入门

给 Student.get_average() 写测试清单（追加到 测试思维.md）：

正常情况：分数 [80, 90, 85] → 85.0
边界情况：空列表 / 只有一个分数 / 分数为 0 或 100
异常情况：分数是字符串 / 分数是负数

### 1、正常情况：  
Student.get_average([80, 90, 85])，输出85.0  
### 2、边界情况：  
Student.get_average([ ])，应提示分数不能为0；  
Student.get_average([80])，分数数量不符合科目数量时，应提示分数数量应与科目总数（5）相同，若有科目分数为0，请输入0；  
Student.get_average([100，100，100])，输出100；  
Student.get_average([0，0，0])，输出0
### 3、异常情况：  
Student.get_average(["你好",77,89])，应提示分数应为数字；
Student.get_average([-88,-76,90])，应提示分数应为正数

# 周四：继承、多态、封装
给 `BankAccount.withdraw()` 写测试清单：
- 正常情况：余额 100，取 50 → 剩 50
- 边界情况：刚好取空 / 取 0 / 取负数
- 异常情况：余额不足时取款 → 应 raise 错误

### 1、正常情况：  
BankAccount.withdraw(50)：余额100，取款后剩下50
### 2、边界情况：
BankAccount.withdraw(100)：余额100，取完，提示余额为0；  
BankAccount.withdraw(0)：提示取款应大于0；  
BankAccount.withdraw(-10)：提示取款金额应为正数
### 3、异常情况：
BankAccount.withdraw(150)：提示余额不足并显示余额
