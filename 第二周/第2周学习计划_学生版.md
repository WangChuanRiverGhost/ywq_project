## 周三（10月21日）：类与对象入门

### 今日重点
- 搞懂「类」和「对象」的区别：类是模板，对象是实例。
- 掌握 `self`、`__init__`、实例属性、类属性、实例方法。

### 学新知识

**1. 类和对象**
```python
class Person:
    """人类"""

    species = "human"          # 类属性：所有实例共享

    def __init__(self, name, age):   # 构造函数：创建对象时自动调用
        self.name = name             # 实例属性：每个实例独立
        self.age = age

    def greet(self):                 # 实例方法：第一个参数永远是 self
        print(f"你好，我是 {self.name}，今年 {self.age} 岁")

p1 = Person("小明", 18)    # 创建对象（实例）
p1.greet()                 # 调用方法
```

**2. 必须搞懂的概念**
- `self` 是谁？—— 指"调用这个方法的那个实例本身"
- `__init__` 什么时候执行？—— 创建对象时自动执行，用于初始化属性
- **实例属性 vs 类属性**：实例属性每个对象各有一份；类属性所有对象共享一份
- 类方法 `@classmethod`、静态方法 `@staticmethod`（了解即可）

**3. 你已经偷偷用过了！**
你在 `todo.py` 里写的这三个，本质就是 OOP 的「继承」：
```python
class MatterNameError(Exception): pass   # 继承了 Exception 这个类
class MatterNumError(Exception): pass
class MatterCheckError(Exception): pass
```
今天你会正式学到"类继承"这个概念，回头看你已经会用了，会很有成就感。

### 今日重点

- 认识 `__str__` / `__repr__` 魔法方法。

### 学新知识

**1. 继承**
```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):          # Dog 继承 Animal
    def speak(self):
        return "汪汪"

class Cat(Animal):          # Cat 继承 Animal
    def speak(self):
        return "喵喵"

d = Dog("旺财")
c = Cat("咪咪")
print(d.speak(), c.speak())   # 多态：同一方法名，不同表现
```

**2. 封装**
- 用 `_name`（约定私有）、`__name`（名称改写）保护属性，通过方法访问
- `super()` 调用父类方法

**3. 魔法方法**
- `__str__`：`print(对象)` 时显示（给人看）
- `__repr__`：调试时显示（给开发者看）

### 今日重点

- 为项目数据层打基础。

### 学新知识

**1. 主键与外键**
- 主键（PRIMARY KEY）：唯一标识一行
- 外键（FOREIGN KEY）：引用另一张表的主键，建立两张表的关联

**2. JOIN 关联查询**
```python
# 两张表：users(用户) 和 orders(订单)，orders.user_id 关联 users.id
# INNER JOIN：只返回两表都匹配的行
# LEFT JOIN：返回左表全部 + 右表匹配的行（没匹配用 NULL 补）
cursor.execute("""
    SELECT users.name, orders.amount
    FROM users
    LEFT JOIN orders ON users.id = orders.user_id
""")
```

**3. 聚合与分组**
- `COUNT()` / `SUM()` / `AVG()` 聚合函数
- `GROUP BY` 分组、`ORDER BY` 排序
